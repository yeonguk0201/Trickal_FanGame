# 다섯째 달 Play-1 종합 플레이테스트

> 시작: 2026-10-01  
> 기준: [19-fifth-month-plan.md](./19-fifth-month-plan.md) Play-1  
> 콘텐츠: 3층, Room 버전 8 / Encounter 버전 12  
> 상태: **진행 중 — 자동 검증과 실제 플레이 기록을 구분하여 관리**

## 1. 확인된 증거

- Floor-1 자동 검증: 1,024 seed×3층, 방 수·연결성·보스 거리·필수 경로와 관련 회귀 6종 통과.
- Floor-1 수동 확인: 사용자 완료 보고(2026-10-01). 층별 시간은 아직 기록하지 않았다고 확인했다.
- seed 1 보조 Run 기록 수신(2026-10-01): 에르핀, 3층 보스 사망, 층별 137.6·167.4·107.1초,
  합계 412.1초(6분 52.1초), `Full SP`·`Invulnerable` 사용. 3층 도달과 보스 사망 종료 기록의 증거이며,
  정상 플레이 시간·난이도 비교에서는 제외한다. 진행 차단·중복 지급·재추첨 여부는 아직 별도 보고가 없다.
  검증기의 가상 시간 테스트와 방 이동 검증은 실제 Run 완료나 플레이 소요 시간으로 기록하지 않는다.
- Play-1 준비 자동 검증: Unity 6000.3.22f1 `Week20Play1Verification.VerifyBatch` 통과, 종료 코드 0
  (2026-10-01). 로그는 `game/Logs/play-1-verification.log`다. 시간 누적·종료 고정·보조 표시·RunSession
  종료 연결, Room-8의 256 seed 재현과 카메라 전환·부분 웨이브 재개·층 재구성 후 중복 드롭 방지,
  Resource-1·3, Obstacle-4, Special-1·2·3·4, Reward-3 회귀를 확인했다.

## 2. 준비와 시간 기록

1. Unity에서 `Assets/Scenes/FrontendScene.unity`를 열고 Play해 Run을 시작한다.
2. `F1` 개발 패널에 seed를 입력하고 `Restart Run with this seed`를 누른다.
3. 패널의 Play-1 영역에서 F1·F2·F3 시간을 확인한다. `Copy Play-1 record`로 현재 기록을 복사한다.
4. 클리어·사망·포기·재시작·Scene 종료 시 Console에 `[Play-1]` 기록이 한 번 남는다. 결과 화면에서도
   `F1` 패널의 `Copy last Play-1 record`로 직전 종료 기록을 복사할 수 있다.
5. 종료 기록과 확인 결과를 아래 표에 남긴다. Console에서 `[Play-1]`을 검색하면 원문을 찾을 수 있다.

시간은 Run 시작부터 **실제 경과 초**로 측정하며 일시정지·보상 선택·메뉴 시간도 포함한다. 방을 오가도
층 누적 시간이 사라지지 않고, 종료 후 결과 화면·저장 대기 시간은 더하지 않는다. 현재 Run DTO의
`playTime` 의미와 같지만, 층별 기록은 개발용 로컬 측정이며 Backend·Web에 전송하지 않는다.

정상 플레이 시간 측정에서는 무적·HP/SP 채우기·자원 추가·웨이브 처치·순간이동·비밀방 표시·강제 구덩이를
끄고 사용하지 않는다. 이런 도구를 사용하면 `assistance`에 표시된다. 개발 도구로 준비한 특수방 기능 확인은
별도 보조 Run으로 기록하며 정상 플레이 시간의 비교 대상에 넣지 않는다. seed 선택과 기록 복사는 보조로
표시하지 않는다. 기록은 확인 결과를 자동으로 판정하지 않는다.

## 3. 실제 플레이 시나리오

권장 구성은 서로 다른 seed의 정상 Run 3회와 필요 시 특수방 보조 Run이다. seed와 층 구성이 확인되면
아래에 기록한다. 정상 Run에서는 최소 한 번은 열쇠·폭탄을 사용하지 않고 보스 경로를 끝까지 진행한다.

| 목적 | seed | 1층 / 2층 / 3층 방 수 | 상태 |
| --- | --- | --- | --- |
| 기본 진행 | 1 | 10 / 10 / 13 | 보조 Run 3층 보스 사망 기록 수신, 정상 Run 대기 |
| 비밀방·상점·잠긴 보물방 포함 | 8 | 8 / 8 / 17 | 구성 확인, 실제 플레이 대기 |
| 3층 최대 규모 | 12 | 8 / 12 / 18 | 구성 확인, 실제 플레이 대기 |

seed 8의 1층에는 비밀방·상점·잠긴 보물방이 모두 있다. seed 12의 3층은 총 18방이다. 이 표의 방 수는
자동 생성 결과이며 실제 플레이를 완료했다는 의미가 아니다. 각 정상 Run에서는 자연 획득한 자원만 쓰고,
자원 부족으로 선택 방을 방문하지 못했으면 미확인으로 적는다. 필요한 기능은 seed 8의 별도 보조 Run에서
자원을 추가해 확인할 수 있다.

각 Run에서 다음 항목을 확인한다.

- 방 이동·웨이브·보스 처치·1→2→3층 진행·3층 종료가 막히지 않는다.
- 장애물에 적이 영구적으로 끼거나 적이 남지 않았는데 문이 잠기는 방이 없다.
- 완료한 방에 다시 들어가도 적·웨이브·클리어 드롭이 다시 생성되지 않는다.
- 파괴한 장애물은 다시 나타나지 않고 파괴 드롭을 두 번 주지 않는다.
- 보물방·비밀방 보상은 한 번만 수령하며 선택 도중 이동하거나 중복 입력해 추가 획득하지 않는다.
- 잠긴 문은 첫 진입에만 열쇠 1개를 소비하고 재방문에는 추가 소비하지 않는다.
- 폭탄 연타로 중복 설치·소비하지 않고, 폭발이 닿은 비밀 벽과 발견 상태가 재방문에도 유지된다.
- 상점 상품·판매 상태·남은 엘리프가 재방문에 유지되고 같은 상품을 두 번 구매하지 않는다.
- 같은 seed와 버전으로 재시작하면 방 배치·Encounter·장애물 후보가 재현된다.
- 사망 또는 클리어 뒤 새 Run에서는 자원·상품 구매·방 진행 상태가 초기화된다.

층을 벗어나면 미획득 일반 바닥 픽업은 사라지는 기존 규칙을 따른다. 층을 다시 구성할 때 드롭이 다시
지급되지 않는 것이 기대 결과다. 재구성 상태는 자동 검증에서도 따로 확인한다.

## 4. 실제 Run 결과

| 날짜 | seed | 캐릭터 | 결과 | 1층 초 | 2층 초 | 3층 초 | 보조 도구 | 진행 차단 | 중복 지급 | 재추첨 | 메모 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-10-01 | 1 | erpin | DIED:BOSS (3층) | 137.6 | 167.4 | 107.1 | Full SP, Invulnerable | 미확인 | 미확인 | 미확인 | 합계 412.1초. 정상 시간·난이도 비교 제외. 무적 사용 시점·해제 시점은 로그에 없으므로 사망 원인을 추가 추정하지 않음 |

수신 원문:

```text
[Play-1] seed=1 character=erpin content=8/12 result=DIED:BOSS real-time-including-pauses: F1=137.6s, F2=167.4s, F3=107.1s; assistance=Full SP,Invulnerable
```

문제가 나오면 seed·층/방 번호·재현 조작·예상 결과·실제 결과를 메모한다. 사망한 Run은 도달한 층까지만
시간을 기록하고 미진입 층은 `—`로 남긴다. 실제 실행하지 않은 시나리오를 통과로 바꾸지 않는다.

보상·특수방 검증으로 기술적 회귀를 확인하고 실제 조작·전투·탐색 시간은 사용자 플레이로 확인한다.
