# 샤샤 실시간 물줄기 비교 프로토타입

작성: 2026-10-12. 갱신: 2026-10-13. 상태: **사용자 실제 Play 비교에서 개선 확인·제작 방향 채택, 커밋 전 Unity 전용 검사·공격/원본 에셋 회귀 통과, 물다운 표현 보강·미확인 Play 조건 대기**.
샤샤 하나를 대표 효과로 비교한 뒤, 사용자는 메시·셰이더·월드 입자 합성을 앞으로의 제작 방향으로 결정했다. 최종 미술 완성이나 모든 검증 완료를 의미하지 않는다.

## 구성과 범위

- 대상: `artifact-shasha-jar`의 기본 공격, 다중 줄기와 커터·팽이의 짧은 연결 줄기.
- `ProceduralWaterStream.cs`: 월드 좌표 띠 메시 80구간, 분출 시간 곡선, 외곽 파동, 별도 물방울 Particle System.
- `ProceduralWaterStream.shader`: URP Universal2D 패스, 시간에 따라 흐르는 노이즈·물결·끊어진 포말, 어두운 외곽과 청록색 내부. 텍스처·프레임 시트·AI 이미지 생성 없이 계산한다.
- 원본 진행 방향은 +X이며 런타임 경로 방향으로 배치한다. v1은 중심선이 직선이고 외곽만 바뀌었으며, 아래 v2에서 양 끝을 고정한 진행 물결로 보강했다. 몸통 장식 폭은 판정 폭의 약 1.44배에 파동을 적용한다.
- 피해 폭·공격 주기·최대 사거리·관통·넉백·시너지 규칙은 유지한다. 본체 표시는 기존 최대 0.12초, 분열·튕김은 0.08초다. 표시 중 발사점과 벽 끝점만 갱신하며 피해를 다시 계산하지 않는다. 방향은 해당 발사 시점 방향을 유지한다.
- 물방울은 World 공간, 최대 96개/줄기로 제한한다. 본체보다 짧게 남아 날아가며 별도 프레임 에셋을 쓰지 않는다. 벽 물보라는 방 안쪽 방향으로 방출하고 현재 벽 끝 평면 밖을 자른다.
- 공격 불가·사망·비활성화·A/B 전환에서 본체와 입자를 제거한다. 위치가 한 프레임에 4월드 단위를 넘게 바뀌면 방 이동/텔레포트로 간주해 잔여 표시를 지운다.
- 시각 효과는 `UnityEngine.Random`을 사용하지 않는다. 입자는 별도 고정 시드로 생성한다.
- 기존 PNG·GUID·씬·프리팹은 교체하지 않았다. 이전에 생성한 분리형 원화 초안은 이번 구현에서 사용하지 않는다.
- 2026-10-13 사용자 비교로 제작 방향은 채택했다. 기존 효과의 일괄 교체와 샤샤 최종 미술 완성은 범위에 포함하지 않는다.

## 실제 게임 비교

1. `Assets/Scenes/SampleScene.unity`를 열고 Play한다.
2. `F1 > — Artifact — > Show artifact drops > Drop 샤샤의 항아리`로 얻는다. 기존 에셋 자동 수집 목록을 사용한다.
3. 획득 후 같은 섹션의 `Shasha: realtime water (off = original)`을 켜면 새 효과, 끄면 기존 이미지다. 기본값은 새 효과이며 전환은 다음 발사부터 적용한다. 전환해도 공격 쿨다운을 초기화하지 않는다.
4. 방향키로 쏘면서 이동하고, 정지·수직·수평·대각선·벽 근처에서 비교한다. 새 효과의 시작점이 플레이어에 붙고 끝점은 벽에 닿는지, 물결이 흐르며 물방울은 플레이어와 별개로 날아가는지 확인한다.
5. 칸나의 대포·다중 투사체·다야의 다이아몬드 커터·칸타의 팽이를 F1 Drop으로 조합한다. 매우 짧은 벽 경로, 여러 줄기, 분열·튕김을 확인한다.
6. 방 이동·사망·일시정지·비교 토글 후 잔여 효과가 남지 않는지 확인한다. 피해 횟수와 발사 주기는 두 표시에서 같아야 한다.

사용자 미술 검수 기준: 실제 게임 크기의 물 가독성, 캐릭터 가림, 이동 중 연결, 벽 접촉, 분출 리듬, 기존 표현보다 자연스러운지. 사용자 확인이 있는 범위만 완료 표시한다.

## 비교 결과와 원인·해결 (2026-10-13)

- 사용자 실제 Play 평가: 새 효과가 기존보다 훨씬 좋다고 확인했다. 더 물줄기처럼 보이도록 모습·보조 효과를 다듬을 여지는 남겼다. 개별 방향·시너지·취소 조건 전체를 확인했다고 확대 해석하지 않는다.
- 기존 방식: 완성된 단일 PNG 전체를 경로 길이에 맞춰 늘렸다. 표면과 외곽이 정적이고 길이에 따라 시작/끝 모양도 함께 변형되어 흐르는 물보다 늘어난 그림처럼 보일 수 있었다.
- 이동 관련 코드상 원인 후보: 플레이어의 자식인 그림이 움직이는 동안 길이는 발사 순간 계산값을 유지했다. 벽 끝점이 갱신되지 않아 접촉 위치가 어긋날 수 있었다. 이 후보를 사용자 영상으로 단독 입증한 것은 아니다.
- 해결: 직선 중심선 위의 메시 외곽·내부 물결을 시간에 따라 변화시키고, 월드 공간 물방울과 벽 물보라를 독립적으로 표시했다. 표시 중 발사점과 벽 끝점을 갱신한다. 공격 판정은 분리해서 유지했다.
- 초기에 정적 분리 원화부터 만든 접근은 사용자가 요청한 실시간 VFX 대안과 달라 제작 방향을 바꿨다. 분리 원화를 런타임에 적용하거나 실패한 애니메이션으로 검증한 것은 아니다.
- 확인 근거: 사용자 실제 비교 발언과 제작 방식 채택 요청. C# 컴파일 확인은 기존 실행 기록을 따른다. 수정 후 전용 검사·기존 공격/원본 에셋 회귀는 2026-10-13 커밋 전 배치에서 통과했다. 개별 Play 조건 전부를 확인한 것은 아니다.

## 확정한 제작 방향과 유지 범위

- 새 효과·어색한 효과 개선은 메시 + 시간 변화 셰이더 + 독립 파티클 합성을 우선 검토한다. 각 요소는 필요한 경우에만 사용한다.
- 모든 효과를 같은 방식으로 강제하거나 이미지·프레임 재료를 폐기하지 않는다. 에르핀 저학년은 현재 사용자가 무난하다고 평가한 표현을 유지하는 후보이며, 폭탄도 현재 외형을 살리는 시간 변화 보강을 우선 검토한다.
- 폭탄은 실제 표시 경로별 프레임 수를 확인한 뒤 발생·팽창·소멸을 보강한다. 이 기록은 폭탄 재제작 완료나 현재 모든 폭발이 단일 프레임이라는 검증을 뜻하지 않는다.
- 현재 기준은 `docs/25-combat-effects-guide.md`에 반영했다.

## v2: 펌프 물결과 접촉 포말 (2026-10-13)

- 본체: 진행 방향으로 이동하는 굵기 맥동과 중심선 굴곡을 합성했다. 양 끝은 경로에 고정하고, 중심 굴곡은 판정 폭의 0.4배 이내로 제한한다. 판정은 기존 직선을 유지한다. 시작·끝에서 0.24월드 단위에 걸쳐 굴곡을 줄여 짧은 경로의 과도한 꺾임을 피한다.
- 표면: 평행한 포말 외에 굽은 가로 물결 마루가 발사 방향으로 흐른다. 본체 길이·공격 주기·피해·시너지는 변경하지 않았다.
- 접촉: 벽 끝점에 별도 메시·셰이더의 부채꼴 청록 포말을 배치하고, 접촉면에서 양옆으로 퍼지는 흰 포말과 방 안쪽으로 되튀는 물방울을 합성한다. 접촉 메시 깊이는 경로 길이로 제한한다. 자유 끝점·분열/튕김 연결에는 벽 충돌 포말을 만들지 않는다. 적은 관통 대상이므로 적 위치에서 본체가 끊어지는 연출은 추가하지 않았다.
- 물방울: 분출 중 최대 초당 60회 방출 기회를 두며 프레임당 몸통 1~5개·접촉 4개, World 공간·최대 96개 제한을 유지한다. 게임의 전역 난수는 소비하지 않는다. 본체/포말은 기존 0.12초 표시 후 사라지고 물방울은 자체 수명으로 감쇠한다.
- Edit Mode 미리보기: `Trickal Fan Game > Effects > Preview Shasha Water`에서 `Open / reset Scene preview`를 누른다. 임시 Preview Scene에 같은 런타임 효과를 만든다. 길이·굵기·방향·벽 접촉, 본체/물방울/접촉 포말 표시, 반복·속도·시간 슬라이더·재시작을 제공한다. 시간 변경마다 고정 시드와 1/60초 간격으로 같은 방출 규칙을 재시뮬레이션한다. 원본 씬 저장이나 피해 로직 호출은 하지 않는다.
- 미리보기 한계: 현재 효과 단독 보기다. 실제 캐릭터·배경 및 기존 이미지 A/B는 SampleScene Play로 확인한다. 시작점 이동 조작과 실제 배경 합성은 후속이다. Unity 6000.3의 내부 `SceneView.customScene` 연결을 지원 여부 확인 후 사용하며, 미지원 Editor에서는 오류를 안내하고 임시 리소스를 정리한다.
