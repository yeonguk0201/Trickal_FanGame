# 황금 메테오 꼬리·착지 폭발 v1

제작일: 2026-11-20. 내장 image_gen으로 기존 본체를 색·화풍 참고 이미지로 사용했다.
본체·꼬리·착지 효과를 독립 에셋으로 유지한다.

## 시트 구성

| 파일 | 배치·순서 | 기준점·방향 | 재생 제안 |
|---|---|---|---|
| saemaeum-gold-meteor-tail-v1-sheet.png | 2열 1행, 왼쪽 → 오른쪽 | 아래로 낙하하며 꼬리는 위로 뻗음. 아래쪽 밝은 끝을 본체 뒤에 겹침 | 60~80ms씩 교대 반복, 착지 시 중지 |
| saemaeum-gold-meteor-impact-v1-sheet.png | 2열 2행, 좌상 → 우상 → 좌하 → 우하 | 납작한 지면 고리. 각 셀의 지면 충돌 중심을 맞춰 사용 | 40 / 80 / 100 / 120ms, 마지막에 알파 감쇠 |

꼬리: 동일한 불꽃의 혀와 내부 흐름이 바뀌는 2포즈.
폭발: 작은 섬광 → 최대 팽창 → 흩어지는 금 조각·먼지 → 잔여 먼지.
꼬리 시트는 1774×887, 셀은 887×887이다. 폭발 시트는 1254×1254, 셀은 627×627이다.
위 시간은 제안이며 게임 피해 타이밍을 변경하지 않는다.

## 검수 상태

- PNG 해상도·RGBA·알파 범위 확인. 생성 원본을 수정 없이 보존했다.
- 사용자 원화·움직임 검수 대기. 연속 재생 및 본체와의 실제 크기 합성은 미확인.
- 시트 생성의 특성상 프레임별 바닥·부착 기준점 보정과 셀 경계의 작은 입자 확인이 필요하다. 폭발 3프레임은 좌측 여백이 좁으므로 정식 분할 전 경계를 재검수한다.
- 마지막 폭발 프레임에 먼지와 조각이 남으므로 재생 종료 시 알파 감쇠가 필요하다.
- Unity 미연결. PPU·피벗·필터·압축·Max Size 미확정. 원화 PNG와 기록만 추가하여 Unity 배치는 생략했다.

정확한 생성 프롬프트는 `animation-prompts.json`에 보존한다.

## 꼬리 v2 — 본체 중첩을 위한 중앙 투명화

- 사용자 피드백: 기존 꼬리 아래쪽이 꽉 차서 본체와 겹치기 어색함. 가운데에 투명도를 주도록 요청.
- `saemaeum-gold-meteor-tail-v2-sheet.png`: 내장 image_gen으로 v1을 편집. 2프레임 배치를 유지하고 아래 중앙을 U자 형태로 비웠다. 안쪽 경계는 반투명하며 양옆 불꽃이 본체를 감싸는 용도다. 기존 v1은 보존했다.
- `saemaeum-gold-meteor-composite-v2-concept.png`: 본체와 v2 꼬리를 참고해 이미지 생성 도구로 만든 단일 합성 시안. 픽셀 그대로의 레이어 합성이나 런타임 재현 증거는 아니며 연결 형태를 검수하는 참고 자료다.
- 정확한 생성 프롬프트: `tail-v2-prompts.json`.
- 새 꼬리의 PNG 규격과 알파, 두 셀의 아래 중앙 투명도를 확인했다. 실제 본체 중첩 위치·크기·2프레임 연속성은 Unity 연결 전 확인 필요. 사용자 검수 대기.
