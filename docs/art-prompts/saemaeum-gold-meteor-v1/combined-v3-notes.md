# 본체·꼬리 일체형 메테오 v3

- 사용자 요청: 첨부 운석처럼 본체와 긴 낙하 꼬리가 붙은 형태로 4프레임 제작.
- 제작: 내장 image_gen. 첨부 이미지는 대각선 구도·본체에서 이어지는 꼬리 흐름만 참고하고 기존 황금 본체는 색·형태·화풍 참고로 사용했다.
- 최종 파일: `saemaeum-gold-meteor-combined-v3-sheet.png`.
- 구성: 2열 2행, 좌상 → 우상 → 좌하 → 우하. 네 셀 각각 본체와 꼬리를 포함한 하나의 메테오다.
- 방향: 왼쪽 아래로 낙하, 꼬리는 오른쪽 위로 이어진다. 기존 수직 낙하 로직과 연결할 때 회전 및 본체 기준점 설정이 필요하다.
- 움직임: 본체 위치·모양을 유지하며 불꽃의 외곽과 내부 흐름이 바뀌는 반복 4포즈를 요청했다. 연속 재생의 정합성은 미검수다.
- 생성 후 좌측 불꽃 잘림을 발견해 각 셀의 여백을 보강한 편집본을 최종 파일로 저장했다. 기존 분리형 에셋은 보존한다.
- PNG 규격·RGBA·알파 범위를 확인했다. 실제 게임 크기 합성·피벗·프레임별 위치 보정·연속 재생·사용자 미술 검수·Unity 연결은 미실시다.
- 재생 제안: 프레임당 60~80ms 반복. 착지 시 이 스프라이트를 종료하고 별도 착지 폭발을 재생한다. 피해 타이밍 변경 없음.
- 원화 PNG와 기록만 추가하여 Unity 배치는 생략했다.
- 정확한 생성·여백 보강 프롬프트는 `combined-v3-prompts.json`에 보존한다.
