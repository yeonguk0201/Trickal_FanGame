# 용사용 한손 공격 시안 v1

- 상태: 사용자 미술 검수 대기. 게임 에셋, 프리팹, 코드에는 미적용.
- 범위: 기본 일반 공격·대쉬·내려찍기, 황금 내려찍기. 각 4자세.
- 사용자 수정 기준: 오른손 한 손으로 검을 잡고, 왼손은 방패만 든다. 두 손 검 자세인 첫 시안은 폐기.
- 기준 원본: `Boss_크레용사용.png`, `CrayonHero_Awakened.png`. 미리보기 폴더에 대기 원본 사본 포함.
- 제작: 내장 image_gen. 원본 알파 유지. 전체 프롬프트는 `prompts.json`.
- 검수: `preview.html`에서 대기 → 동작 → 대기 재생, 정지, 다음 자세, 속도, 좌우 반전, 대기 겹치기 제공.
- PNG는 생성 원본이며 균일 셀 경계를 일부 넘는 검·망토가 있어 현재 Unity 임포트용 최종 시트가 아니다. 미리보기는 해당 경계를 보정해 표시한다.
- 미리보기 배율·발 기준점·타이밍은 미술 비교용 임시 값이다. 실제 Unity 이벤트와 검광·지면 충격은 연결하지 않았다.
- 미확인: 사용자 미술 승인, 최종 프레임 정리, Unity PPU·피벗 및 Play 연속성 검수.
- Unity 배치: 원화 및 별도 HTML 시안만 생성했으므로 생략.
