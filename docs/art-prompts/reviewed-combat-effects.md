- 그림자: 너비가 높이의 약 세 배인 부드러운 검정·회색 바닥 그림자, 중앙부터 가장자리까지 투명해짐.

직선 경로는 셰이더가 주황 배경과 넓은 빨간 화살표 3개를 그린다. 화살표는 같은 속도로 이동하며
앞쪽이 나갈 때 뒤쪽에서 다음 화살표가 들어온다. 검수본의 200px 경로에서 42px/s인 최종 속도는
전체 경로의 0.21배/초, 화살표 반복 주기의 0.63배/초로 옮겼다. 개별 화살표에 점멸을 넣지 않았다.
착지 그림자는 피해 범위 전체를 의미하지 않는다.

적 피격은 이미지 없이 0.28초간 빨간 내부 윤곽·반투명 색상 점멸을 코드와 셰이더로 처리한다.
별도로 표시하는 보스 본체와 일반 적의 변형 메시에도 적용하며 원본 tint를 보존한다.
플레이어 무적 점멸, 기존 에르핀 충돌·돌진 표시는 유지한다. 돌진 잔상은 추가하지 않는다.

검증 진입점은 `ReviewedCombatEffectsVerification.VerifyWithRegressionsBatch`다.
Unity 6000.3.22f1 배치 종료 코드 0과 성공 로그를 확인했다. 에셋·셰이더, 실제 회복 이벤트,
보스 표시 스프라이트의 피격 점멸, 평평한 착지 그림자와 취소 시 제거를 검사했다.
저학년 스킬, 크레용사용 공격, 보스·일반 적 이동 검증도 통과했다.
로그는 로컬 `output/vfx-review-v1/unity-effects-verification.log`에 있다.
기존 Boss-2 종합 검증의 HUD-2 입력 차단 실패는 이 조각에서 수정하지 않았다.
실제 Play 화면에서 크기·투명도·가독성 검수는 별도로 남아 있다.

## v5 — 검격 확대·직선 내려찍기·굵은 화살표

사용자의 참고 이미지에 맞춰 내려찍기는 곡선 검격과 분리했다. 새 8프레임 시트는 직선으로 뻗는
상아색·금빛 검광과 날카로운 금색 광선을 사용한다. 4번째 프레임에서 가장 강하게 터지고,
마지막에는 작은 불꽃으로 소멸한다. 생성 후 프레임 여백과 잔광을 수정했다.
수평 원본을 실제 공격 방향으로 회전하며, 기존 내려찍기 피해 시점과 방향 수는 유지한다.
표시 길이는 slashLength의 1.35배, 너비는 실제 표시 본체와 공격 폭을 기준으로 잡고 0.4초 재생한다.

근접 검격은 기존 1.4배 표시에서 2배 표시로 확대했으므로 약 1.43배 커졌다.
표시 시간을 0.25→0.35초로 늘렸다. 본체 크기에 맞춘 최소 너비를 적용한다.
경로 예고는 높이 전체를 채우는 굵은 빨간 꺾쇠를 셰이더로 그리며, 빨강 불투명도는 0.78이다.
세 화살표의 좁은 간격과 연속 이동·속도 0.63주기/초를 유지한다.
용사용의 예고 너비는 max(기존 dashWidth의 1.35배, 표시 본체 너비의 1.1배)이며,
시각 효과의 크기만 바꾸고 피해 판정은 바꾸지 않는다.

로컬 검수 페이지 v5에는 별도 내려찍기와 확대 검격을 추가했다. `검수 프레임`으로 1~8프레임을
고정해서 확인할 수 있다. Unity 검증 로그는 `output/vfx-review-v1/unity-effects-v5-verification.log`다.
Unity 6000.3.22f1에서 7개 이미지·3개 셰이더 검사와 관련 전투 회귀가 통과했고,
로그의 배치 종료 코드 0을 확인했다. 검수 페이지의 수정한 세 효과 표시도 확인했다.
실제 Play 화면의 가독성은 사용자 검수 대상으로 남겨 둔다.

## v6 — 지면 내려찍기·화살표 세 개 묶음

용사용의 대시 경로 예고를 제거했다. 대시 방향 고정·횟수·이동·피해와 공격 모션은 유지한다.
일반 적은 빨간 화살표 팔 두께를 v5의 약 72.5%로 줄였으며 세 개를 한 묶음으로 이동시킨다.
200px 검수 경로 기준 묶음 주기는 300px, 속도는 기존 42px/s이며 묶음 사이에는 빈 간격이 있다.
Unity 셰이더와 검수 페이지 모두 같은 반복 주기를 사용한다.

`sword-slam.png`는 사용자 지면 스케치를 참고해 다시 생성했다.
현재 생성본은 `exec-5a6166ec-f52d-48cf-8e06-8240dc93b6b2`다.
금빛 바닥 균열에서 위로 뾰족한 검광과 작은 갈색 돌 파편이 솟으며 뒤쪽으로 갈수록 낮아진다.
떠 있는 직선 빔을 제거하고, 기존 8프레임·0.4초 및 실제 내려찍기 피해 시점에 연결했다.
원본 두 행의 지면 높이가 달라 각 행 pivot Y를 0.14/0.24로 맞춰 지면이 튀지 않도록 했다.
에셋 GUID는 보존했다. 검수 페이지 v6의 앞 세 카드에서 확인한다.
이번 Unity 검증 로그는 `output/vfx-review-v1/unity-effects-v6-verification.log`다.
7개 이미지·3개 셰이더 및 관련 전투 회귀가 통과했으며 배치 로그의 종료 코드 0을 확인했다.
검수 페이지 v6의 세 화살표 묶음과 지면 내려찍기 표시를 확인했다. 실제 Play 가독성 검수는 남아 있다.

## v7 — 내려찍기 방향·시작점·과도한 확대 수정

사용자가 제공한 실제 게임 화면에서 내려찍기가 보스와 겹치고 방 밖까지 길게 늘어나는 문제를 확인했다.
큰 충격 부분을 진행 방향의 앞쪽에 두도록 Sprite를 좌우 반전했다. 새 GroundSlam 셰이더는
URP의 Sprite 반전 처리를 사용하고 세계 좌표로 방 내부 경계를 잘라낸다.
시작점은 보스 표시 너비의 절반과 Collider 반경 중 큰 값에서 0.3유닛 더 앞이다.
표시 크기는 본체 너비 기준 2.5~5유닛이며, 벽과 실제 공격 끝점까지 남은 길이로 더 줄인다.
가로·세로에 같은 크기를 적용해 원본 비율을 보존한다. 앞 공간이 0.6유닛 미만이면 표시를 생략한다.
기존 공격 방향·피해·범위는 유지하며, 이펙트가 공격 범위 전체를 표시하는 것은 아니다.
전 방향·대형 본체·벽 근접 배치 검사를 추가했다.
검증 로그: `output/vfx-review-v1/unity-slam-layout-verification.log`.
Unity 6000.3.22f1의 배치 로그에서 종료 코드 0과 이펙트 배치·4개 셰이더 및 관련 전투 회귀 통과를 확인했다.
Play에서 큰 충격 부분의 방향, 몸 앞 간격, 방 경계 밖 잘림과 각성 3방향을 사용자에게 재확인받는다.

## v8 — 방 크기에 맞춘 내려찍기

사용자 요청으로 최대 5유닛 제한을 제거했다. 표시 길이는 몸 앞 시작점에서 진행 방향의
방 경계까지 남은 거리에서 0.15유닛을 뺀 값이다. 가로·세로에 같은 크기를 적용해 원본 비율을
유지하며, 방향 반전·몸 앞 간격·지면 anchor와 방 밖 잘라내기를 유지한다.
큰 방에서도 5유닛이나 기존 공격 길이로 시각 효과를 제한하지 않는다.
피해 판정은 기존 설정을 유지한다. 검증기는 전 방향의 방 경계 도달과 18유닛보다 긴 표시를 검사한다.
검증 로그: `output/vfx-review-v1/unity-slam-room-fit-verification.log`.
Unity 6000.3.22f1에서 배치 종료 코드 0과 배치·셰이더 및 관련 전투 회귀 통과를 확인했다.
실제 Play 화면에서 커진 내려찍기의 가독성 확인은 남아 있다.

## 지면 Artwork의 상하 반전 수정

사용자가 일부 방향에서 상하가 뒤집히는 문제를 보고했다. 공격 각도를 그대로 적용하면
왼쪽 방향에서 Sprite 전체가 180도 회전했다. 표시 각도는 -90~90도로 유지하고,
왼쪽 방향은 좌우 반전으로 처리하도록 바꾸었다. 큰 충격 부분의 전방 방향과 지면 기준점을 보존한다.
검증기에 15도 간격의 전 방향에서 전방 충격·상하 유지 검사를 추가했다.
로그: `output/vfx-review-v1/unity-slam-upright-verification.log`.

추가 연출 제안은 지면 균열·돌 파편과 별도의 높은 검광을 분리하는 방식이다.
검광의 높이·두께는 공격 경로 길이와 별개로 정하고 셰이더 기반으로 표시해
돌 파편 확대와 래스터 늘림을 피한다. 높은 검광 이후 지면 충격이 이어지는 순서를 추천했다.

## 확정 제작 원칙 — 독립 이펙트 합성

2026-10-06 사용자가 검광과 지면 충격을 분리하는 방향을 확정했다.
앞으로 여러 이펙트를 겹쳐 완성해도 되며, 독립적인 조절이 필요한 요소를 하나의 시트에 묶지 않는다.
이 원칙은 저장소 `AGENTS.md`의 이펙트 제작 지침에도 반영했다.

용사용 내려찍기의 다음 제작 기준은 두 효과의 독립 구성이다.

- 검광: 위에서 내려오는 긴 칼날 빛. 높이·두께·발생 시각을 별도로 조절하며 셰이더 방식도 사용한다.
- 지면 충격: 검광이 바닥에 닿을 때의 균열·돌 파편. 지면 기준점과 파편 크기를 별도로 유지한다.

각 효과를 개별 검수한 뒤 합성 상태에서도 방향·타이밍·몸체 가림을 확인한다.
현재 생성된 `sword-slam.png`는 지면 충격용으로 사용한다.

## v9 — 검광과 지면 충격 분리 적용

별도 `SlamLightEffect`와 `SlamLight.shader`를 구현해 실제 내려찍기 시점에 합성했다.
검광은 0.1초 동안 내려오며 최대 크기를 0.7초 유지한 다음 0.22초에 걸쳐 사라진다.
높이는 본체 표시 너비의 1.6배(5~9유닛)로 정해 경로가 짧아도 낮아지지 않는다.
검광 길이는 몸 앞에서 방 경계까지 유지하고, -90~90도 표시 각도로 상하 반전을 방지한다.
셰이더 방식이므로 검광을 크게 표시해도 래스터 해상도에 의존하지 않는다.

지면 충격은 본체 너비의 0.55배(2~3.5유닛)를 기준으로 원본 비율을 보존한 작은 조각을
경로 전체에 이어 표시한다. 검광이 닿는 0.1초 뒤부터 조각마다 0.02초 간격으로 발생하며
각 조각의 8프레임은 0.4초간 재생된다. 돌 파편 크기를 검광 높이와 독립적으로 유지한다.
각 효과는 일시정지 시 정지하고 소유자 비활성화·파괴·방 이동 시 정리된다.
실제 공격의 피해·범위·돌진 예고 제거는 기존대로 유지한다.

Unity 6000.3.22f1 배치에서 5개 셰이더, 최대 크기 유지·감쇠, 전 방향 배치와
저학년 스킬·용사용 공격·적 이동 회귀가 통과했으며 종료 코드 0을 확인했다.
로그: `output/vfx-review-v1/unity-layered-slam-verification.log`.
웹 검수 v9의 내려찍기 카드에서 검광과 지면 충격을 개별 표시할 수 있다.
웹은 셰이더 형태·시간을 재현한 미리보기이며 실제 Play 화면의 가독성 검수는 남아 있다.

## v10 — 검수 반려 후 두 시트 재제작

v9의 빗금이 있는 삼각형 검광과 규칙적인 지면 충격 반복 배치는 사용자 검수에서 반려됐다.
검광과 지면 충격을 모두 image_gen으로 다시 생성했다. 독립 레이어 원칙은 유지한다.

## v11 — 지면 충격 제거·검광 방향과 시작점·차징 바라보기 수정

2026-10-07 사용자가 제공한 Play 화면에서 지면 충격의 크기 불일치와 검광의 간격을 확인했다.
지면 충격의 런타임 발생을 제거하고 검광의 좌우 방향을 v10과 반대로 변경했다.
검광 시작 간격은 이미지 너비의 0.5배 + 0.3유닛에서 너비의 0.2배와
Collider 반경의 0.8배 중 큰 값으로 줄였다. 등록 이미지의 투명 여백으로 생긴 과도한 간격을 줄인다.
최대 크기 유지 0.7초와 방 경계까지의 길이는 유지한다.

BossMovementAnimator는 공격 포즈에서 이동량 대신 LockedDirection의 X 방향으로
본체와 실제 Artwork의 좌우 반전을 갱신한다. 정지한 차징 중에도 조준을 따라 바라보며,
수직 조준은 마지막 좌우 방향을 유지하고 방향이 고정된 뒤에는 그 방향을 유지한다.
일반·각성 차징에서 왼쪽→오른쪽→왼쪽 전환 및 수직 유지 회귀 검사를 추가했다.
최신 검증 로그는 `output/vfx-review-v1/unity-slam-facing-verification.log`다.
Unity 6000.3.22f1에서 새 차징 방향 검사와 검광 배치·셰이더·관련 전투 회귀가 통과했고
배치 종료 코드 0을 확인했다. 웹 검수 v11에서 좌우 반전과 지면 충격 제거를 확인했다.
Play 화면에서 검광 방향·몸 앞 간격·차징 바라보기를 재검수한다.

## v12 — 검광 기준선을 실제 경고 경로에 일치

2026-10-07 사용자 Play 화면에서 검광이 경고 경로와 다른 곳에 표시된다는 피드백을 받았다.
기존의 본체 간격·방 경계 기반 별도 배치 대신, 실제 LineRenderer의 시작·끝 세계 좌표를
그대로 `SlamLightEffect.PlayPath`에 전달한다. 경고가 고정된 뒤 타겟이 이동해도 같은 경로를 사용한다.
일반 1방향 및 각성 3방향 모두 각 경고 선에 직접 연결한다. 이미지의 지면 기준선은 이 경로에 놓이며
검광의 높이, 좌우 반전과 0.7초 최대 유지, 지면 충격 제거는 유지한다.
방 경계 밖은 셰이더로 잘라내므로 방 내부에서 경고의 경로를 따라 표시한다.
15도 간격 전 방향에서 기준선 양 끝점이 경고와 0.001유닛 이내로 일치하는 검사를 추가했다.
검증 로그: `output/vfx-review-v1/unity-slam-path-alignment.log`.
Unity 6000.3.22f1 배치에서 경고 경로 일치 검사와 관련 전투 회귀가 통과했고 종료 코드 0을 확인했다.
실제 Play에서 경고 선 위치와 내려찍기 기준선의 겹침은 추가 검수한다.

## v13 — 아래로 소폭 이동·맵에 잘리지 않는 전체 크기 맞춤

2026-10-07 사용자 화면 피드백으로 검광 기준점을 경고 시작점에서 세계 Y -0.25유닛 이동했다.
경고의 방향은 유지한다. 방 내부에 0.1유닛 여유를 두고 회전된 이미지 전체 네 꼭짓점이
들어가는 최대 배율을 계산하여 가로·세로를 같은 비율로 줄인다. 모든 프레임의 빛·끝부분까지
들어가도록 전체 캔버스를 기준으로 하며, 방이 충분히 크면 원래 크기를 유지한다.
기존 셰이더 경계 잘라내기는 제거했다. 일반·각성 각 방향에 같은 계산을 적용한다.
검광의 좌우 반전·0.7초 최대 유지와 지면 충격 제거는 유지한다.
중앙·벽 근처에서 15도 간격의 전 방향 전체 꼭짓점 포함, 이동 기준점·비율 보존 및
넓은 방 원래 크기 유지 검사를 추가했다.
검증 로그: `output/vfx-review-v1/unity-slam-full-room-fit.log`.

실제 Play에서는 아래 이동량과 경계 근처 축소 크기의 가독성을 추가 검수한다.

## v14 — 높이 유지·경로 길이만 조절·경계에서 자연스럽게 감쇠

2026-10-07 v13의 전체 캔버스 축소로 필살기 크기가 작아진 사용자 피드백에 따라
높이를 경로 길이와 다시 독립시켰다. 몸 크기 기준의 기존 5~9유닛 높이는 유지하고,
경고 시작점에서 세계 Y -0.25유닛 이동한 경로의 길이만 방 경계 0.1유닛 앞까지 줄인다.
검광 전체를 같은 비율로 축소하는 계산은 제거했다.

셰이더는 실제 픽셀 세계 좌표를 기준으로 방 경계 안쪽 0.8유닛 구간에서 부드럽게 감쇠한다.
방 밖 픽셀은 투명하며 `clip`으로 잘라내지 않는다. 진행 방향 끝부분도 약 0.8유닛
(짧은 경로에서는 길이의 최대 30%) 구간에서 투명해지도록 처리한다.
일반·각성 모든 경로에 같은 규칙을 적용한다. 좌우 반전, 차징 바라보기와 최대 프레임
0.7초 유지, 지면 충격 제거는 유지한다.

검증기는 전 방향·벽 근처에서 경로 끝이 방 안에 있고 높이가 줄지 않는지,
1유닛 미만 경로에서도 원래 높이를 유지하는지 확인한다.
최신 로그: `output/vfx-review-v1/unity-slam-independent-height.log`.
Unity 6000.3.22f1에서 높이 유지·경로 배치·셰이더와 관련 전투 회귀가 통과했고 종료 코드 0을 확인했다.
실제 Play에서 큰 검광의 가독성과 경계 감쇠의 자연스러움은 추가 검수한다.
