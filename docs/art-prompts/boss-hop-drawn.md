# 부스러기·금고 에셋 기반 도약 (2026-10-04)

내장 imagegen으로 두 보스의 Idle·준비·체공·착지 포즈 시트를 각각 만들었다. 원본 비율과 정체성, 방향, 바닥선을 유지하고 크림/팔 또는 슬라임/뚜껑/진주의 개별 움직임으로 탄성을 표현한다. 전역 스케일 변형은 적용하지 않는다.

적용 폴더: `game/Assets/Art/Bosses/FairyKingdom/Movement/`. `Buseureogi_Hop_0..3.png`·`Vault_Hop_0..3.png`는 모두 640×640, 400 PPU다. 시트의 실제 투명 행 간격으로 포즈를 분리하고, 각 주기에 하나의 동일한 배율을 적용해 원본 Idle 높이에 맞추고 기준점을 등록했다. 금고는 왕관까지 담도록 캔버스만 위아래 확장하며 접지선의 월드 좌표는 기존 보석 레이어와 맞췄다. 바닥 보석은 포즈 시트에 포함하지 않고 기존 분리 레이어를 유지했다. 실제 높이·이동과 착지 피해는 런타임이 처리하며, 모양 변화는 그려진 프레임만 담당한다.
