# 용사용 내려찍기 재제작 — v15 대표 원화

2026-10-07. [전투 이펙트 제작 가이드](../25-combat-effects-guide.md)의 대표 원화 검수 단계다.
최신 게임 적용은 아래 2026-10-08 v21 Unity 연결 기록을 따른다.
v15~v21 원화 제작 중의 v14 적용 문구는 당시 상태를 기록한 이력이다.

## 목적과 사용처

- 용사용 내려찍기의 실제 고정 경로에 표시할 큰 검광을 다시 제작한다.
- 흰 중심과 금빛 가장자리, 위에서 바닥으로 내려오는 날카로운 실루엣을 우선 확인한다.
- 사용자 스크린샷의 잠정 수용한 좌우 형태를 기준으로 원본의 높은 봉우리를 오른쪽에 두었다.
- 지면 충격과 돌 파편은 제외한다. 공격 범위·타격 시점·차징 규칙은 이번 단계의 변경 대상이 아니다.
- 기존 v14의 세계 Y -0.25 보정, 실제 경고 경로 재사용, 상하 반전 방지와 최대 형태 0.7초 유지는 후속 구현에서도 검토할 기준이다.

## 제작 구성과 후속 계획

| 요소 | 현재 단계 | 다음 단계 |
|---|---|---|
| 큰 검광 | 최대 강도 단일 원화 후보 | 미술 승인 뒤 발생·유지·소멸 프레임 제작 |
| 접지 빛 | 후보 원화에 형태 포함 | 승인 뒤 가변 길이용 시작·몸통·끝 구성 검토 |
| 지면 충격 | 제외 | 핵심 검광 승인 후 필요할 때만 별도 제작 |

이 후보는 전체 형태 검수용이다. 최종 런타임 레이어 분리·가변 길이·방 경계 처리를 구현한 결과가 아니다.
원화 검수에서 형태가 바뀌면 먼저 후보를 수정한다. 전체 시트부터 만들지 않는다.
검광 높이를 경로 길이에 따라 일괄 축소하거나 넓은 경계 감쇠로 흐리게 하는 방식은 피한다.

- 알파 범위: 0~254 확인. 원본 픽셀은 수정하지 않고 복사했다.
- 잔광 축소 편집 후보 `exec-3013eca0-1934-4fc6-b2e8-5f3899c772f2`, `exec-232d7e37-1376-4ecf-878a-8a2d9307f635`는 목표만큼 잔광이 줄지 않아 채택하지 않았다.

## v16 — 사용자 스케치 반영과 높이 유지 비교

사용자 참고 `스크린샷 2026-10-06 225323.png`의 긴 톱니 형태를 반영했다.
오른쪽의 큰 검광에서 왼쪽의 작은 검광들이 이어져 맵 끝까지 빛이 보이는 형태다.

같은 검수 페이지에서 v16·v15·기존 시트를 비교한다. 벽까지 거리를 줄이면 용사용의 배치도 벽 쪽으로 이동한다.

높이 유지 모드의 전체 가로 압축을 최종 구현 방식으로 확정하지 않는다.
한 원화를 중간에서 잘라 붙이는 초기 실험은 봉우리 중간의 수직 절단면이 보여 검수 페이지에서 제거했다.

권장 최종 구성은 높이가 고정된 큰 검광, 줄이거나 생략할 중간 작은 검광, 벽 앞에서 자연스럽게 끝나는 검광이다.

극히 짧은 경로에서는 큰 검광의 가로 두께나 전용 짧은 형태를 조절한다.
높이 유지의 실제 방 상단·대각선 경계 처리는 미확인이다. 방의 세로 공간까지 무제한으로 넘겨도 된다는 승인은 아니다.

v16은 대표 원화 검수 대기다. 실제 적용은 v14 유지, 시트·런타임 레이어·0.7초 유지 애니메이션 제작 전이다.

## v19 — 작은 지면 접촉 보조 효과

돌 파편·먼지·넓은 잔광은 포함하지 않았다.

- 사용처: 내려찍기 검광이 바닥에 닿는 순간의 짧은 보조 타격감. 피해 경로나 판정을 변경하지 않는다.

- 도구: built-in image_gen. 참고는 채택한 `slam-middle-v18.png`의 흰색·금색과 날카로운 선이다.
- 생성 ID: `exec-96b5bc49-713a-4127-a19e-d1b8b0de80d6`. 생성 픽셀을 수정하지 않고 복사했다.
- 정확한 프롬프트: `output/vfx-review-v1/slam-v19-prompt.json`.
- 기준점: 검광 접지선 아래 14px, 원화 Y 530/724를 바닥 기준으로 한 시각적 가정.

## v20 — 바닥으로 퍼지는 충격파와 튀는 흙·돌

모듈은 방 경로 안에 들어가는 고정 중심에 배치한다. 검광 높이로 충격파를 확대하지 않는다.
정렬은 충격파 → 검광 → 공중 파편 순서다. 좌우 반전만 적용하여 바닥의 상하를 보존한다.

파편은 경로 100px당 기본 2개로 긴 경로 14개, 짧은 경로 약 9개다.
실제 채색 폭 8~16px, 원본 비율 유지, 최대 0.075초의 발생 차이를 둔다.
파편별 수평 속도·상승 속도·회전과 중력 포물선으로 흩어지고 내려온다.
바닥에 도달한 뒤 아래로 관통하지 않도록 위치를 제한하고 0.10초에 걸쳐 추가 감쇠한다.
수명은 0.62~0.78초이며 접지 후 0.90초 이후에는 모두 제거한다.
시점 슬라이더를 되돌려도 같은 입자 배치를 볼 수 있도록 결정적 수열을 사용한다.
기존 피해 범위·판정·캐릭터 동작·Unity 에셋은 변경하지 않았다.

검수 화면에 충격파·파편 개별 켜기/끄기, 파편 밀도 1~4, 파편 크기 60~160%,
보조 효과 단독 보기와 타격 순간 정지를 추가했다. 기존 v19 화면은 `slam-ground-v19-review.html`로 보존했다.
현재는 브라우저 합성 후보이며 새 보조 효과의 사용자 미술 검수와 Unity 적용은 대기다.
원화 파티클 이동/확장 프리뷰를 프레임별 검광 시트 제작 완료로 처리하지 않는다.

브라우저에서 긴/짧은 경로의 검광 합성·보조 효과 단독 표시, 0.48초 발생과 0.70초 확산,
오른쪽 방향 740/450px 경로, 1.40초의 충격파·파편 제거를 확인했다. 오류/경고 로그는 없었다.

## v21 — 옆 조각과 이어지는 뾰족한 충격파

사용자 요청으로 원형/타원형 충격파를 수평으로 이어지는 뾰족한 띠로 교체했다.

닫힌 고리·둥근 끝부분은 제거했다. 검광과 흙·돌 입자는 기존 원화와 타이밍을 유지한다.

## 2026-10-08 — 승인 v21 Unity 연결

사용자가 v21 검수를 수용하고 Unity 적용을 요청했다. 검수한 원화 5개를 Resources에 원본 그대로 복사했다.

기존 Scene/Prefab과 기존 이펙트 meta는 수정하지 않았다.
장기 보관용 생성 프롬프트는 `docs/art-prompts/crayon-hero-slam-v21-prompts.json`이다.

모두 Texture Default, 원본 크기/NPOT 유지, Max Size 4096, Bilinear, Clamp,
밉맵 없음, 비압축, sRGB·Alpha Is Transparency 설정이다. 메시에 원본 텍스처/UV를 직접 사용하므로
Sprite 피벗·PPU는 임포트에서 사용하지 않는다. 좌표 환산 기준은 검수 50px=1유닛이다.
파편 시트는 2×2, 627px 셀의 내부 채색 영역과 4px 여백을 UV로 선택한다.

`CrayonHeroBossPatternRuntime.TickMapSlash`의 기존 `SlamLightEffect.PlayPath` 진입점에서
`LayeredSlamEffect`를 생성한다. 공격 경고의 고정 시작·끝, 세계 Y -0.25 보정,
방 안의 경로 길이, 상하가 뒤집히지 않는 각도와 좌우 표시 규칙을 재사용한다.
검광은 단일 원화 3개를 아래 방향 순차 노출·이동·소멸로 합성한다. 프레임별 시트로 제작한 결과는 아니다.
기존 최대 프레임 시트는 더 이상 내려찍기의 검광으로 사용하지 않는다.

- 검광: 높이는 기존 보스 크기 기반 5~9유닛, 내려오기 0.14초·최대 유지 0.7초·소멸 0.28초.
- 중간 조각: 기본 폭 6유닛, 끝 조각 4.8유닛. 원본 비율을 유지하며 경로에 따라 개수와 겹침을 조절한다.
- 원화 폭보다 좁은 경로: 큰 검광의 오른쪽 UV 창만 표시한다. 전체 원화를 가로 압축하지 않고 높이를 유지한다.
  잘린 시작 면에는 최대 0.08유닛의 좁은 감쇠를 적용한다. 매우 짧은 전용 원화를 완성한 것은 아니다.
- 충격파: 기본 폭 4.8유닛·강도 55%, 접지선 아래 0.16유닛. 높이와 파편 크기는 검광 높이에 종속하지 않는다.
  바닥 중심선을 공유하며 확대된 끝을 겹친다. 긴 방에서도 발생 지연은 최대 0.075초로 제한한다.
  초단거리에서 충격파가 경로 폭보다 커지지 않도록 해당 조각만 비율 유지 축소한다.
- 파편: 기본 경로 유닛당 1개(최대 128개), 실제 폭 0.16~0.32유닛. 상승·중력·회전·낙하와 바닥 도달 후 감쇠.
- 정렬: 보스 기준 충격파 -1, 검광 +1, 파편 +3. 방 경계는 별도 셰이더에서 0.035유닛 구간만 감쇠한다.
- 수명 종료·원본 비활성·사망·4유닛 이상 순간 이동 시 전체 오브젝트를 제거하고 동적 메시를 해제한다.
- 피해 계산/시점·차징·일반 및 각성 공격 규칙은 변경하지 않는다. 준비 0.30초는 웹 검수용 대기이며 런타임에서 추가하지 않는다.

공통 효과·하급 스킬·용사용 공격 모션·적 이동 회귀가 통과했다.
