# 폭탄 폭발 불씨·충격파 v1

Motion-0 조각. 플레이어 폭탄(`PlacedBomb`)의 기존 폭발 원화(`effect-bomb-explosion`, 0.15초)는 그대로 두고,
그 둘레에 실시간 보조 효과 두 개를 더했다. 사용자 요청(2026-10-16): "불씨 효과랑 살짝 터지는 약간의 충격파 느낌".

## 목적과 사용처

- 발생 이벤트: `PlacedBomb.ApplyExplosion`. 폭발 장애물(`ConfigureUnowned`)도 같은 폭발이라 함께 나온다.
- 전달 정보: 폭발 반경(기본 2)과 폭발 뒤의 여운.
- 피해 반경·시점·대상, 원화 표시 시간과 크기는 바꾸지 않았다.

## 제작 구성

| 레이어 | 제작 방식 | 크기 규칙 | 타이밍(초) | 정렬 |
|---|---|---|---|---|
| 충격파 링 | 쿼드 + `MuffinExplosion` 셰이더 링 모드, 불투명도 0.8, 노이즈 침식 | 바깥 가장자리가 반경 0.45 → 1.0, 피해 반경에서 멈춤 | 0.03 ~ 0.34 | 원화 −2 |
| 불씨 | Particle System 18개, World, Stretch(느려지면 둥근 점), 셰이더 불씨 모드(5) | 크기 0.09 ~ 0.16 × (반경/2), 반경 × 0.9 안 | 0에 방출, 수명 0.45 ~ 0.78, 살짝 떠오름 | 원화 −1 |

- 둘 다 원화 아래에 그린다. 원화가 보이는 0.15초 동안은 원화를 어지럽히지 않고, 원화가 사라지면 넓어지는 링과 남은 불씨가 드러난다.
- 불씨 모드(`_Mode` 5)는 속이 찬 주황 구슬이다. 폭발 머핀이 쓰는 불꽃 모드(3)는 승인된 상태 그대로 두었다.
- 런타임: `game/Assets/Scripts/Combat/BombBurstEffect.cs`. 정적 카운터·해시 시드로 `UnityEngine.Random`을 소비하지 않는다.
  설치한 플레이어가 순간 이동(4 이상)하거나 비활성이면 즉시 제거한다. 소유자가 없는 폭발 장애물은 0.8초 뒤 제거된다.
- Scene 뷰 미리보기: `Trickal Fan Game/Effects/Preview Bomb Burst`. 원화·링·불씨 표시 전환, 피해 반경, 시간 조절. 배경 합성은 지원하지 않는다.

## 검수와 검증

- 대표 형태: Edit Mode 정지 렌더 `output/art-review/bomb-burst/unity-frames.png`. Claude가 렌더를 보고 세 번 조정했다(불씨가 너무 작음 → 속 빈 고리처럼 보임 → 원화 위에서 지저분함). 사용자 확인 뒤 불씨를 0.14 ~ 0.24에서 0.09 ~ 0.16으로 가늘게 하고 "딱 좋다"며 수용(2026-10-16).
- 자동 검증(2026-10-16): `BombBurstVerification.VerifyAndExportBatch` 종료 코드 0. 셰이더, 원화 아래 정렬, 링이 피해 반경을 넘지 않고 도달,
  원화 뒤까지 남는 불씨와 반경 안 유지, 0.8초 뒤 잔여 없음, 같은 시드 재현과 `UnityEngine.Random` 미소비.
- 커밋 전 회귀(2026-10-16): `BombBurstVerification.VerifyWithRegressionsBatch` 종료 코드 0 (새 효과, 같은 셰이더를 쓰는 폭발 머핀, 요정왕국 원화 연결, Special-2 폭탄 규칙, `output/bomb-burst-precommit.log`).
- 실제 Play: 폭발 장애물·벽 근처·연속 폭발의 개별 조건은 기록된 확인 근거 없음. 폭탄을 `F`로 설치해 터뜨리고, 폭발 장애물·벽 근처·연속 폭발도 함께 본다.
