# 검광 상단 잘림 수정

내장 image_gen 편집으로 잘린 검광의 끝을 복원하고 투명 여백을 확보했다. 기존 파일은 보존하며 새 파일은 Golden_Charge_1_Unclipped.png, Golden_Charge_2_Unclipped.png, Golden_Charge_3_Unclipped.png다.

상단 경계 알파 검사: 1·2단계는 비투명 픽셀 0개, 3단계는 고립된 잔여 픽셀 1개다. 시각적으로 검광의 끝과 위쪽 여백을 확인했다. 미리보기 제작 및 게임 적용은 하지 않았다.
생성 도구가 프레이밍과 출력 크기를 바꿨으므로 기존 PPU를 그대로 공유하는 최종 임포트 파일이 아니다. 연결 시 투구 크기와 발 위치를 기준으로 배율·피벗 등록이 필요하다.

편집 지시: 기존 캐릭터 비율·자세·한손 검·방패·색감과 단계별 검광을 유지하며 캔버스를 확장하고, 잘린 검광의 상단을 자연스러운 끝과 투명 감쇠로 복원. 모든 효과와 양쪽 날개를 화면 안에 포함. 상단이 다시 잘린 중간 결과는 제외했다.
