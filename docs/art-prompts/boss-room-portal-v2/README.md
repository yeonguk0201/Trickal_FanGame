# 보스룸 포탈 v2 — 외곽 고정

## 수정 이유와 기준
- 2026-11-19 사용자 제공 GIF에서 v1이 제자리에서 일렁이기보다 통째로 흔들려 보인다는 피드백.
- v1의 독립 생성 프레임은 테두리 위치·형태가 달랐고 런타임이 전체 스프라이트를 교체했다.
- 기존 원화를 참조해 매끈한 타원형 테두리와 내부 물결로 재제작. 생성 파일: exec-c9f3d990-a1ad-4b8a-9560-ab5838a01b11.png.

## 최종 구성
- 원본 시트: `portal-idle-4frames.png`, 2열×2행, 좌상→우상→좌하→우하.
- 런타임: `Resources/CombatEffects/boss-room-portal-idle.png` 교체, 기존 meta/GUID 보존.
- 생성 프레임의 외곽이 픽셀 단위로 같다고 가정하지 않는다. 첫 셀만 SpriteRenderer에 고정하고 `PortalInterior.shader`가 내부 RGB만 전환한다.
- 실루엣 알파·외곽 테두리·메시·피벗은 첫 프레임으로 고정. 중앙 타원 마스크의 내부에서만 SmoothStep 교차 전환하며, 테두리에 닿기 전에 영향이 0으로 줄어든다.
- 4장 × 0.5초 = 2초 반복. 입자·지면 레이어 추가 없음. 등장 0.65초, 방 중앙 위치, 포탈 판정과 드롭 밀어내기는 기존 유지.
- PPU 220, 중심 피벗, Bilinear/Clamp, mipmap 없음, 무압축. 홀수 높이 시트의 가운데 1행 제외 규칙 유지.

- 수동: Game Scene → F1 → Boss F1/F2 → 보스 처치. 외곽이 고정되고 내부만 천천히 변하는지 확인.
- 원화 및 실제 Play 미술 승인 대기. 코드상 외곽 고정 검사를 미술 승인으로 간주하지 않는다.
- 최종 검증: Unity 6000.3.22f1 단독 Verify 종료 코드 0, 성공 로그 확인 (`game/Logs/portal-v2-verification.log`). 미리보기 창 포함 컴파일 통과. PNG 1312×1199 RGBA 및 투명 모서리 확인. 관련 코드/기록의 `git diff --check` 통과.

## 후면 오로라 (2026-11-19)
- 사용자 요청: 포탈 뒤에서 포탈과 비슷한 그라데이션으로 일렁이는 빛.
- `PortalAurora` + `PortalAurora.shader`: 독립 메시 레이어의 보라·청록 그라데이션, 두 겹의 부드러운 타원형 빛띠와 잔광. 외곽은 알파로 0까지 감쇠하며 사각 경계가 보이지 않게 한다.
- 생성 이미지 추가 없음. Unity 셰이더에서 빛띠의 굴곡·밝기·색 흐름을 연속 계산한다.
- 기본 크기 3.2×3.6, 밝기 0.55, 속도 1. 포탈과 같은 sorting layer에서 order -1. 그림자·콜라이더 없음.
- 포탈 클리어/등장 시간과 공유하여 전투 전 숨김, 등장 0.65초에 맞춰 밝아짐. 포탈 본체 좌표·실루엣·판정에는 영향 없음.
- 런타임 PortalAurora 컴포넌트에서 크기·밝기·속도·양끝 색을 독립 조절 가능. Play 조절은 영구 설정 저장과 구분한다.
- 미리보기는 같은 메시·셰이더와 단일 12초 시계를 사용. `Portal layer`, `Aurora layer` 토글로 합성/단독 확인, 시간 역이동·Restart 지원. 포탈 내부는 2초, 오로라는 기본 12초 주기.
- 미리보기의 단색 배경은 실제 방 배경과 다르므로 실제 Play의 가독성·미술 승인은 별도 확인한다.
- 검증 확장: 클리어 전 오로라 숨김, 포탈 뒤 정렬, 셰이더 오류, 등장 중 밝아짐, 재구성 시 중복 레이어 없음.
- `FloorPortalArtworkVerification.VerifyAndCaptureBatch`: 단독 검사 후 `game/Logs/portal-aurora-preview.png`에 Unity 렌더 정지 화면 출력. 회귀 묶음은 호출하지 않는다.
- 최종 자동 검증: Unity 6000.3.22f1 `VerifyAndCaptureBatch` 성공 로그 및 종료 코드 0 확인 (`game/Logs/portal-aurora-verification.log`).
- Unity 정지 렌더 `game/Logs/portal-aurora-preview.png`를 직접 확인: 후면 보라·청록빛, 부드러운 외곽 감쇠, 선명한 본체 유지. 실제 Play 연속 움직임과 사용자 미술 수용은 대기.

### 후면 빛 수정 — 방사형 감쇠 (2026-11-19)
- 사용자 피드백: 두꺼운 고리 느낌을 없애고 끝으로 갈수록 옅어지며 약간 방사형으로 일렁일 것.
- 기존 반경별 두 띠의 밝기 피크를 제거. 포탈 뒤쪽에서 시작해 거리 증가에 따라 지수·거듭제곱 감쇠하며 외곽에서 완전 투명해진다.
- 각도별 부드러운 광선 두 패턴에 약한 굴곡과 중심→바깥 진행 위상을 적용. 메시·포탈 본체는 고정하며 빛의 길이감과 밝기만 변화한다.
- 기존 크기·색·등장·미리보기 제어는 유지. 정지 렌더 및 단독 검사 후 실제 Play 미술 수용은 별도.
- 검증: Unity `VerifyAndCaptureBatch` 종료 코드 0 및 성공 로그 확인 (`game/Logs/portal-aurora-radial-verification.log`). 새 정지 렌더에서 두꺼운 외곽 고리가 사라지고 짧은 방사형 빛이 배경으로 옅어지는 것을 확인. 연속 Play 미술 확인은 사용자 검수 대기.

### 고리와 연결되는 후광 (2026-11-19)
- 사용자 피드백: 방사형 효과가 기존 고리와 이질적이며 고리 가까이 진하고 바깥으로 옅어지는 자연스러운 연결이 우선. 크기는 커도 됨.
- 별도 보라/청록 팔레트를 제거하고 고정된 첫 프레임의 고리에서 각도별 3개 반경 색을 알파 가중으로 가져온다. 원화의 금빛·분홍·보라·청록 위치를 그대로 잇는다.
- 원화 중심과 타원 반경을 셀/PPU로 환산해 후광 기준점을 맞춘다. 최대 메시 크기 4.8×5.2, 기본 밝기 0.8.
- 고리 바로 밖에서 진한 접촉광과 넓은 잔광이 각각 지수 감쇠한다. 외곽 사각 경계에서도 0으로 감쇠한다. 방사형 변화는 최대 약 10%의 낮은 대비로 제한한다.
- 색 설정은 원화에서 자동 추출하며 컴포넌트에서는 크기·밝기·속도를 조절한다. 기존 문서의 보라·청록 색 직접 조절 설명은 이 버전에서 대체한다.
- 자동 검증과 실제 Play 미술 수용은 별도 기록한다.
- 최종 단독 검증·렌더: Unity 종료 코드 0 (`game/Logs/portal-rim-glow-verification.log`). 고리 색이 이어지는 후광과 외곽 감쇠를 정지 렌더로 확인했다. 커진 후광 전체가 보이도록 미리보기/캡처 카메라 크기를 2.8로 조정했다. 실제 Play 연속 움직임과 사용자 미술 승인은 대기.

### 사각 후광 경계 수정 (2026-11-19)
- 사용자 지적: 후광이 네모로 보임. 이전 정지 렌더 검수에서 이를 놓쳤음.
- 원인: UV 네 변까지의 최소 거리로 알파를 감쇠하여 사각 메시 모양이 후광에 남았음.
- 수정: 포탈과 동심인 타원 반경만으로 외곽 감쇠. 메시 반폭/반높이 안쪽 90%에서 빛이 완전히 0이 되므로 사각 경계에 닿지 않음.
- 렌더 검증 추가: 실제 캡처 픽셀을 4px 간격으로 확인해 타원 바깥이 배경색과 같은지 검사. 컴파일 성공만으로 외형 문제를 통과시키지 않음.
- 최종 Unity 배치 종료 코드 0. 기존 단독 검사 및 `Portal rendered ellipse boundary verification passed` 확인 (`game/Logs/portal-ellipse-verification.log`). 새 렌더에서 사각 외곽 대신 타원형으로 사라지는 잔광을 확인. 실제 Play 미술 승인은 대기.
