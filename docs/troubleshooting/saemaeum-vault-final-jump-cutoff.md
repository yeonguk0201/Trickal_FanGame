# 새마음금고 마지막 점프가 중간에 끊기는 문제

## 1. 증상과 재현

새마음금고의 점프를 횟수와 무관하게 일정한 리듬으로 바꾸기 위해 1페이즈 점프당 시간을 `0.69초`,
2페이즈를 `0.62초`로 설정했다. 2페이즈에서 6회 점프가 선택되면 마지막 도약 중 보스의 공중 위치와
시각 효과가 갑자기 지면 상태로 복원되며 Recovery로 넘어갔다.

## 2. 원인

점프 런타임은 실제 시퀀스 길이를 `점프 횟수 × 점프당 시간`으로 계산했지만, `BossController`의
Active 상태 종료는 기존 Pattern 정의의 고정 `3.8초 × 2페이즈 템포 0.88`인 `3.344초`를 사용했다.
6회 점프의 실제 길이는 `3.72초`이므로, 마지막 점프가 끝나기 약 `0.376초` 전에 상태 전환이 발생했다.

## 3. 해결

점프 시퀀스 시작 시 실제 시작 시각과 선택된 점프 횟수를 저장하고, 계산된 마지막 착지 시각으로
`BossController`의 Active 종료 시각을 동기화했다. 따라서 점프가 적게 선택되면 불필요한 대기 없이
끝나고, 6회가 선택되면 마지막 착지·피해·충돌 복원이 끝난 뒤 Recovery로 전환한다.

## 4. 검증과 재발 방지

Boss-2 자동 검증은 2페이즈 6회 점프를 강제로 선택해 마지막 착지 직전에는 Active 상태를 유지하고,
착지 직후에만 Recovery로 전환되는지 확인한다. 해당 검증과 Boss-0~2·HUD-5 회귀는 Unity 6000.3.22f1
배치에서 종료 코드 `0`으로 통과했다.

점프처럼 런타임에서 실제 지속 시간이 결정되는 패턴은 Pattern 정의의 기본 Active 시간만으로 종료하지
않고, 선택된 횟수와 개별 실행 시간을 반영해 상태 종료 시각을 함께 맞춘다.
