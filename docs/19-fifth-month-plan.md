## 1. 이 문서의 역할

넷째 달에는 화면 흐름, 전투 HUD, Room Profile·Template, Encounter, 일반 적 3종과 층별 보스,
아티팩트·스펠 선택 보상을 완성했다. 다섯째 달에는 반복 플레이에서 드러나는 다음 문제를 해결한다.

1. 방 내부가 비어 있거나 고정 기둥 하나뿐이라 같은 크기의 방이 비슷하게 느껴진다.
2. Encounter가 조합 단위로만 선택되고 웨이브당 1~3마리여서 같은 방의 적 구성이 자주 반복된다.
3. 방 난이도라는 개념이 없어 층 안에서 쉬운 방과 어려운 방의 흐름을 설계할 수 없다.
4. 열쇠·폭탄·엘리프 같은 탐색 자원이 없어 보스 직행과 탐색 사이의 선택이 약하다.
5. 층당 6~8방에 특수방이 보물방뿐이라 층 구조의 변화가 적다.

이번 달은 **탐색 자원 → 파괴 가능한 장애물과 Layout → SpawnPoint 후보와 방 난이도 →
특수방과 층 규모 확장** 순서로 진행한다. 방 내부는 계속 사람이 설계한 Layout을 기준으로 하고,
정해진 후보 안에서만 제한적으로 랜덤화한다.

## 2. 시작 시점의 확정 기반

### 완료된 게임 흐름

- 타이틀 → 로컬 프로필 → 홈 → 캐릭터 선택 → Run → 결과의 Frontend 흐름
- 3층 Run, 층당 6~8개의 seed 기반 격자형 방, 보스 최소 거리 3의 막다른 방 배치
- 시작방·일반 전투방·보물방·보스방
- Small·Basic·Wide·Tall·Large Room Template, 고정 기둥 Template, 층별 보스방 Template
- Template과 분리된 Encounter 계약, 2웨이브, 역할 기반 SpawnPoint 해석과 안전거리
- 추적형·원거리형·돌진형과 고속형·저격형 변형, 층별 보스 3종
- 반 칸 단위 플레이어 HP와 피해 등급, 적 HP 10배 스케일
- 아티팩트·스펠 통합 후보 3개 중 1개 선택 보상
- 재방문 시 웨이브·보상 상태 보존과 중복 지급 방지

### 이번 달의 제품 방향

- 방 내부 지형과 SpawnPoint는 임의 좌표에 흩뿌리지 않고 Layout에 미리 설계한다.
- 적 구성은 Layout·SpawnPoint 배치 역할·Encounter 후보의 적합성을 확인한 뒤 선택한다.
- 같은 Run seed와 콘텐츠 버전에서 Layout·장애물 드롭·Encounter·스폰 후보 선택을 재현한다.
- 소모 자원이 없어도 필수 진행 경로는 항상 완료할 수 있다.
- 탐색 자원과 방 상태는 Run 한정이며, Backend와 Web 계약은 필요한 경우에만 확장한다.
- 기존 Room·Encounter·장애물 안정 ID의 의미를 바꾸거나 재사용하지 않는다.

## 3. 다섯째 달 최종 완료 조건

2027-01-04까지 다음 흐름을 한 게임 안에서 반복할 수 있어야 한다.

```text
Run 시작
  → 장애물 배치가 다른 방에서 전투
  → 장애물을 부수며 체력·SP·엘리프·열쇠·폭탄 획득
  → 시작방에서 멀수록 어려운 방이 나올 확률이 높은 층 진행
  → 열쇠로 잠긴 방을 열거나 폭탄·구덩이로 비밀방 발견
  → 보스 처치 후 다음 층
  → 클리어 또는 사망
```

### 플레이 경험 완료 조건

- 같은 크기의 방이라도 장애물 Layout에 따라 이동 경로와 공격 판단이 달라진다.
- 같은 방 Layout이라도 스폰 위치별 후보 때문에 적 구성이 Run마다 달라진다.
- 층 안에 쉬운 방과 어려운 방이 섞이고, 먼 방일수록 어려운 방이 나올 확률이 높다.
- 장애물 파괴와 전투 드롭으로 얻은 자원을 선택 경로에 쓸 수 있다.
- 적이 장애물에 끼어 전투가 멈추거나 방을 클리어할 수 없는 상황이 없다.
- 전체 Run을 여러 seed로 완료하며 자원·보상·방 상태의 중복 지급이나 재추첨이 없다.

- 체력 회복 픽업은 1칸(2 단위)을 회복하며, 회복량 전부가 최대 HP 아래에 들어갈 때만 획득한다.
  최대 HP이거나 반 칸만 비었으면 줍지 않고 바닥에 남으며, 플레이어가 밀 수 있는 충돌체로 동작한다.
  `Pickup` 레이어는 Player·Environment·Pickup과만 충돌해 적과 투사체는 하트를 통과한다.
  (사용자 확정, 2026-09-28)
- 엘리프·열쇠·폭탄은 모두 보유 한도 99다. 픽업 하나는 1개를 주고(엘리프도 1짜리 한 종류), 일부만 들어가면
  99까지 채우고 나머지는 버린다. 이미 99면 줍지 않고 체력 회복 픽업처럼 밀 수 있게 바닥에 남는다.
  자원은 `RunProgress`가 보유하며 Run 종료 후에는 획득하지 않고, 새 Run은 0개에서 시작한다.
  (사용자 확정, 2026-09-28)
- 일반 전투방은 클리어 시 한 번 드롭을 추첨한다. 33% 확률로 하트 30·SP 30·엘리프 20·열쇠 12·폭탄 8
  가중치 중 하나가 나오고, 방 seed로 재현하며 재방문·층 재로드 시 다시 추첨하지 않는다. 기존 SP 확정
  클리어 보상과 적 처치 시 25% SP 드롭은 저학년 스킬이 강해서 삭제한다. 드롭 표는 `ResourceDropTable`
  에셋이며 Obstacle-1의 장애물 드롭도 종류별 표를 따로 둔다. (사용자 확정, 2026-09-28)
- 폭탄은 이번 주차에 획득·보유까지만 만든다. 사용 입력과 폭발은 20주차 Special-2에서 만든다.
- 비밀방 통로(구덩이)는 비밀방이 필요하므로 20주차 Special-3에서 만든다.
- Resource-2는 [10장](#10-병행-후보--확정-후속-ux)의 우측 HUD 재배치와 영역이 겹치므로 배치
  우선순위를 함께 정한다.

  입사각으로 나눈다. `80°` 이상인 얕은 접촉은 기존 종료 시각을 유지한 채 접선 방향으로 미끄러지고,
  `80°` 미만인 정면·모서리 충돌과 플레이어·문 충돌은 즉시 회복한다. 경로 판정의 몸통 `0.9`배 여유는
  일반 적의 벽면 이동과 A\* 경로가 공유하므로 유지했다. Obstacle-0 자동 검증에 `80°` 경계 미끄러짐,
  정면 정지와 미끄러짐의 기존 돌진 시간 준수를 추가해 통과했고, Obstacle-3 Play Mode의 장애물 방
  20개·입구/엄폐 40회도 전 적 공격 도달·장애물 미진입·전 웨이브 클리어로 다시 통과했다.
  추가 피드백에서 첫 충돌 뒤 벽에 밀착한 채 다음 돌진을 시작하면 같은 충돌 쌍에 `OnCollisionEnter2D`가
  다시 오지 않아 한 번 막히는 원인을 확인했다. `OnCollisionStay2D`도 같은 법선 판정을 사용하게 연결하고,
  진입·유지 콜백 존재와 반복 스침 판정의 접선 안정성을 자동 검증한다.
  재피드백에서 법선 내적의 절댓값이 벽에서 멀어지는 돌진도 정면 충돌로 취급하는 결함을 추가 확인했다.
  벽으로 접근하는 접촉만 각도를 판정하고, 이탈·평행 이동은 원래 방향을 보존하도록 수정했다.
  다중 접촉에서도 벽으로 가장 강하게 접근하는 법선을 선택한다. 직선·대각선 이탈 회귀와
  Obstacle-0 기존 적 배치는 종료 코드 0으로 통과했다. 이미지의 문 장벽 접촉 여부는 미확정이며,
  문 충돌의 즉시 회복 규칙은 유지한다.
  (실제 플레이에서 벽 밀착 후 재돌진 체감 수동 재확인 대기)

- **돌진 예고 확정 규칙 (2026-09-29)**: 경로 검사와 우회는 예고 전에 수행한다. 예고 중에는 플레이어를
  추적 조준하고, 예고 종료 순간 방향을 고정해 돌진한다. 예고 도중 플레이어가 엄폐하거나 경로가
  막혀도 돌진을 취소하지 않는다(사망·넉백 등 행동 억제는 기존 취소 유지). 몸통 반경으로 검사한
  첫 Environment 접촉 지점까지 예고선을 표시하며, 접촉 이후 미끄러지는 경로까지 예측하지는 않는다.

# 7. 확정 규칙

## 7.1 장애물 (2026-09-28)

- 장애물은 플레이어·적·투사체·돌진을 모두 막는다.
- 기본적으로 플레이어 공격과 폭탄으로만 파괴된다. 적 투사체·돌진 등 다른 주체의 파괴는
  보스 패턴처럼 명시한 예외에서만 허용한다. 기존 부스러기 크림·반죽 장애물의 HP 기반 파괴와
  보스 접촉 파괴는 이 예외로 유지한다.
- 파괴는 피해량이 아닌 타격 횟수로 판정한다. 기본 장애물은 플레이어 공격 5타에 파괴되고,
  공격력 증가는 필요 타격 수를 줄이지 않는다. 폭탄은 타격 수와 관계없이 즉시 파괴한다.
  후속 장애물은 종류별로 필요 타격 수를 따로 정할 수 있다.
- 장애물은 파괴 시 아이템을 드롭할 수 있다. 드롭 확률은 장애물 종류별로 1~5% 범위에서 정하고
  기본 장애물은 3%다. 드롭이 발생하면 아래 가중치로 후보 하나를 고른다.

  | 후보                | 가중치 |
  | ------------------- | -----: |
  | 체력 회복           |    25% |
  | SP                  |    25% |
  | 열쇠                |    10% |
  | 폭탄                |     8% |
  | 엘리프              |    30% |
  | 비밀방 통로(구덩이) |     2% |

- 후속 장애물 종류를 추가하면 장애물마다 드롭 후보를 나눠 맡기고 확률을 다시 조정한다.
  드롭 표는 장애물 종류별 데이터로 두어 이 조정을 코드 수정 없이 할 수 있게 한다.
- 드롭 판정은 방 seed와 콘텐츠 버전으로 재현하고, 드롭은 장애물당 한 번만 생성한다.
- 비밀방 통로는 파괴된 장애물 자리에 구덩이로 나타나며 해당 층 비밀방으로 이어진다.
  폭탄 벽 파괴와 함께 비밀방 진입 방식 두 가지 중 하나다.
- `1 × 1` 유닛 장애물을 기본 단위로 만들고, 여러 칸 형태는 1칸 장애물의 조합으로 구성한다.
- 기존 `central-pillar`(`3 × 3`, 파괴 불가)는 안정 ID와 의미를 바꾸지 않고 고정 지형 예외로 유지한다.
- 파괴 상태는 `RoomRunState`에 보존해 재방문 시 되살아나거나 다시 추첨되지 않는다.

## 7.2 SpawnPoint와 스폰 위치별 후보 (2026-09-28, Spawn-2 확정 2026-09-30)

- SpawnPoint는 장애물 배치와 함께 Layout마다 따로 소유한다. 장애물 Collider 안과 필수 통로에는
  둘 수 없고, 원거리 역할 지점은 전투 영역으로의 사선을 확보해야 한다.
- SpawnPoint에 후방 사격·근접 압박·돌진 경로 같은 배치 역할을 지정한다.
- 역할은 조합 가능한 마스크다. 현재 3지점 Template은 기존 2근접 웨이브와 3원거리 교차 사격을
  보존하기 위해 1·2번 지점을 `근접 압박 + 후방 사격`, 3번 지점을 `후방 사격 + 돌진 경로`로 둔다.
  추적형·고속형은 근접 압박, 원거리형·저격형은 후방 사격, 돌진형은 돌진 경로 지점만 사용할 수 있다.
  보스는 전용 방과 별도 생성 흐름을 사용하므로 이 일반 Encounter 적합성 계약의 대상이 아니다.
- Encounter 슬롯은 한 역할 대신 가중치가 있는 후보 적 목록을 가질 수 있다. Template은 위치와
  배치 역할만, Encounter는 적 후보만 소유하는 경계를 유지한다.
- 적 종류와 SpawnPoint를 독립적으로 추첨하지 않고, Layout·Encounter·배치 역할의 적합성을 확인해 선택한다.
- 후보 선택은 방 seed와 콘텐츠 버전으로 결정하고 선택 결과를 생성 노드에 남겨 재방문 시 재추첨하지 않는다.
- 같은 웨이브의 각 지점은 후보를 독립적으로 추첨하며 같은 적이 여러 번 나올 수 있다. 현재 후보 가중치는
  다음과 같다.

  | 배치 역할 | 프로필 | 후보 가중치 |
  | --- | --- | --- |
  | 근접 압박 | 전체 | 추적형 70 / 고속형 30 |
  | 후방 사격 | Small | 일반 원거리형 90 / 저격형 10 |
  | 후방 사격 | Basic | 일반 원거리형 80 / 저격형 20 |
  | 후방 사격 | Wide | 일반 원거리형 50 / 저격형 50 |
  | 후방 사격 | Tall | 일반 원거리형 50 / 저격형 50 |
  | 후방 사격 | Large | 일반 원거리형 40 / 저격형 60 |
  | 돌진 경로 | 전체 | 돌진형 100 |

- 일반 원거리형은 저격형의 정지 사격 패턴과 분리해 선호 거리 띠에서 한 방향으로 계속 선회하며
  이동 사격한다. 선호 거리는 저격형의 70%인 `5.6`, 이동 속도는 `3.25`, 피해 등급은 중이다.
  플레이어 현재 속도를 기준으로 최대 `0.25초`까지 짧게 예측 사격하며, `0.4초` 간격으로 3발 60% / 4발
  40% 묶음을 발사하고 마지막 탄 직후 정지해 `1.5초` 쉰 뒤 다음 묶음과 함께 이동을 재개한다.
  정해진 위치로 복귀하지 않고 벽·장애물·다른 적에 막혔을 때만 선회 방향을 바꾼다.
  전용 아트가 준비되기 전까지 `QuickRangedFairy`는 저격형 Sprite를
  다른 색으로 표시하는 임시 Prefab을 사용한다.
- 프로필마다 `pressure`와 `crossfire` 안정 ID Encounter를 둔다. `pressure`는 활성 출입구 때문에 중앙
  SpawnPoint를 쓸 수 없는 Small 방에서도 배치 가능한 2점 조합이고, `crossfire`는 안전할 때 3점과
  돌진 경로를 사용한다.
- Spawn-1에서 역할 호환 후보가, Spawn-2에서 후보 선택 규칙과 Encounter ID가 달라졌으므로
  `encounterContentVersion`을 각각 6과 7로 올렸다.

## 7.3 위협 점수와 방 난이도 (2026-09-28, Difficulty-1 확정 2026-09-30)

- 적 역할마다 위협 점수를 둔다. 점수는 런타임에 적을 채우는 예산이 아니라 Encounter 난이도
  검증에 사용한다. 스폰 위치별 후보가 만드는 최소·최대 합계가 선언한 난이도 범위를 벗어나면 검증이 실패한다.
- 방 난이도는 Encounter 난이도에 장애물·함정에 따른 Layout 보정을 더해 정한다.
- 층마다 허용 난이도 범위를 둔다.
- 시작방에서 멀수록 높은 난이도가 선택될 **확률만** 높인다. 가까운 방도 어려울 수 있고 먼 방도
  평이할 수 있으며, 거리로 난이도를 고정하지 않는다.
- 엘리트 적은 후속 추가 후보다. 위협 점수 체계는 엘리트를 나중에 넣을 수 있게 역할별 값으로 설계한다.
- 확정 값은 `Assets/Encounters/room-difficulty-table.asset`에 둔다. (사용자 확정, 2026-09-30)

  | 역할 | 추적형 | 고속형 | 일반 원거리형 | 저격형 | 돌진형 |
  | --- | ---: | ---: | ---: | ---: | ---: |
  | 위협 점수 | 2 | 3 | 3 | 4 | 4 |

- Encounter는 선언 위협 범위를 가진다. 각 슬롯 후보의 최소·최대 점수 × 수량을 모두 더한 합계가 선언 범위를
  벗어나면 Encounter 검증과 층 생성이 실패한다. 현재 `pressure`는 10~14, `crossfire`는 15~19다.
- 방 점수 = 실제로 추첨·저장된 적의 위협 합계 + Room Template의 Layout 보정이다. 장애물 Layout 3종은 +1,
  빈 방·기둥 방은 0이다. 등급은 쉬움 11 이하, 보통 12~15, 어려움 16 이상이다.
- 층별 허용 방 점수는 1층 0~18, 2층 0~20, 3층 0~22이며 상한만 둔다. 범위 밖 조합은 그 층 후보에서 빠지고,
  남는 후보가 없으면 층 생성이 명시적으로 실패한다.
- 각 일반 전투방은 층 안 일반 전투방의 최단~최장 시작방 거리를 0~1로 정규화해 목표 등급을 추첨한다.
  가장 가까운 방 쉬움 40 / 보통 45 / 어려움 15에서 가장 먼 방 10 / 40 / 50으로 선형 보간하며, 모든 방의
  거리가 같으면 중간값을 쓴다. 목표 등급의 후보가 있으면 그중에서, 없으면 가장 가까운 등급의 후보에서
  고른다(같은 거리면 두 등급을 합친다).
- 방 점수·등급·목표 등급·가능 등급은 생성 노드에 남아 재방문 시 다시 추첨하지 않는다. 선택 규칙이 바뀌어
  `encounterContentVersion`을 8로 올렸다.

## 7.4 적 수와 층 규모 (2026-09-28, Encounter-4 확정 2026-09-30)

- 일반 전투방 적 수는 방 전체 2~7마리, 웨이브당 최대 4마리이며 한 웨이브의 후방 사격(일반 원거리·저격)
  슬롯은 최대 3이다. 난이도 표에 두고 위반하는 Encounter는 층 생성에서 명시적으로 실패한다. (사용자 확정)
- SpawnPoint는 기존 1~3번의 좌표·역할을 유지하고 4번부터 추가한다. Small 4, Basic·Wide·Tall 5, Large
  (빈 방·기둥 방·장애물 Layout 3종) 6개다. 추가 지점은 모두 근접 압박 + 후방 사격이고, Small 4번만
  돌진 경로까지 겸해 수직 출입구가 열린 Small 방에서도 돌진형을 둘 수 있다.
- 프로필마다 두 조합을 추가했다. `swarm`(다수 약한 적)은 추적 70 / 고속 30 후보만으로 Small·Basic·Wide
  3+3, Tall·Large 4+3마리다(위협 12~18 / 14~21). `elite-pair`(소수 강한 적)는 돌진형 1 + 저격형 1의
  1웨이브다(위협 8, 쉬움). Small·Basic·Wide는 수직 출입구가 열리면 중앙 근접 지점을 못 써서 웨이브당 3마리로 뒀다.
  두 조합은 15가지 출입구 조합 모두에서 배치된다. 선택 대상이 바뀌어 `encounterContentVersion`을 9로 올렸다.
- 층당 방 수는 현재 6~8개에서 특수방(상점·잠긴 보물방·비밀방) 추가와 함께 늘린다.

## 7.6 적의 장애물 대응 (2026-09-29)

- **이동**: 목표까지 몸통 크기의 직선이 비어 있으면 지금처럼 직선으로 이동한다. 막히면 적 주변을
  `0.5` 유닛 격자로 나눈 A\* 경로를 따라 장애물을 우회하고, 보이는 가장 먼 경로점을 향해 움직인다.
  경로는 `0.25`초마다 다시 계산하며 같은 배치에서는 같은 경로가 나온다. 경로가 없으면(갇힘)
  직선 방향으로 되돌아가 물리 충돌에 맡긴다. 추적형, 원거리형의 접근, 돌진형의 추적,
  저격형의 사선 확보 이동에 적용한다.
- **원거리형**: 공격 거리 안이라도 플레이어까지의 사선이 장애물에 막히면 쏘지 않고 우회 이동한다.
- **저격형**: 사선이 막혀 있으면 조준을 시작하지 않고 우회 이동한다. 조준이 끝나는 순간 사선이
  막혀 있으면 발사하지 않고 재배치로 돌아간다.
- **돌진형**: 플레이어까지 직선이 비어 있을 때만 예고를 시작한다. 막혀 있으면 추적 시간이 지나도
  우회 추적을 계속하며 매 틱 다시 확인한다. 예고를 시작한 뒤에는 경로가 막혀도 취소하지 않고
  마지막 조준 방향으로 돌진한다. 실제 충돌에서만 스침은 미끄러지고 정면 충돌은 회복한다.
- 보스는 보스방에 장애물이 없으므로 이번 규칙의 대상이 아니다.
- 적끼리의 충돌과 플레이어 픽업은 장애물로 취급하지 않는다. 판정 대상은 `Environment` 레이어다.
- **원거리형 후퇴** (Obstacle-3 추가): 최소 공격 거리 안으로 들어온 플레이어에게서 물러날 때 직선 후퇴가
  막히면 좌우 45° 방향을 확인해 비어 있는 쪽으로 물러난다. 세 방향이 모두 막히면(장애물·벽에 몰림) 제자리에서
  사격한다. Obstacle-3 검증에서 기둥 방의 원거리형이 기둥에 등을 붙인 채 이동도 사격도 하지 않고 멈춘 사례로
  추가했다. (2026-09-29, 사용자 확인 필요)

# 9. 이번 달 후보 — Room Layout 확장

필수 조각이 끝났거나 규칙이 확정되면 진행한다. 넷째 달 계획에서 옮긴 항목이다.

| 구성             | 제작·선택 방식                                                |
| ---------------- | ------------------------------------------------------------- |
| Room Layout      | 벽·출입구·통로를 수작업으로 배치                              |
| 장애물·함정      | 기본 위치와 회피 공간을 수작업으로 설계                       |
| 일부 장식·파괴물 | 미리 지정한 안전한 후보 위치에서 랜덤 활성화                  |
| 적 종류·조합     | 해당 Layout에 맞는 Encounter 후보 중 랜덤 선택                |
| 일부 SpawnPoint  | 선택한 Encounter에 적합한 지점 또는 spawn group을 랜덤 활성화 |

- [x] Room Profile의 방 크기·카메라 계약과 연결되는 수작업 Room Layout을 구성한다. (Obstacle-2 Unity 배치 검증, 2026-09-29)
- [ ] 좁은방·넓은방·가로/세로 일자방·ㄱ자방·ㄴ자방·초대형 방을 Room Template 후보로 만들고,
      출입구 조합과 이동 가능한 영역을 수작업으로 검증한다.
- [ ] 직사각형이 아닌 방은 하나의 연결된 이동 영역과 카메라 경계, Encounter 영역, 미니맵
      실루엣을 함께 제공한다.
- [ ] 세로로 긴 방 한쪽에 작은 방 두 개가 연결되는 구성을 실험한다. 방향당 연결 하나 대신
      `left-upper`, `left-lower` 같은 안정 port ID를 사용하고 문 슬롯·안전 진입점·미니맵 선도 같은
      포트를 참조하게 한 뒤 기존 단일 문 방과의 호환 방식을 정한다.
- [ ] 한 화면에 다 들어오지 않는 긴 방·초대형 방에서는 카메라가 플레이어를 따라가되 방 경계
      밖을 비추지 않도록 제한하고, 방 전환 시 다음 방의 카메라 규칙으로 부드럽게 넘긴다.
- [x] 직사각형 Small·Basic·Wide·Tall·Large는 14주차의 축별 카메라 계약으로 먼저 구현한다. (Room-6 Unity 배치 카메라·Prefab 검증, 2026-09-16)
      ㄱ자·ㄴ자처럼 단일 사각 경계가 빈 공간을 비추는 형태만 여러 카메라 구역을 갖는 후속
      Room Template으로 확장한다.
- [ ] 기존 `16 × 9` 한 화면 방을 삭제하지 않고 작은 방 템플릿으로 보존해 추적 카메라 방과 같은
      Run에서 비교한다.
- [ ] 같은 방 크기와 적 조합으로 빈 방, 기둥이 있는 방, 고정 함정이 있는 방을 비교한다.
- [ ] 장애물로 사선을 끊거나 함정의 안전 시간에 접근하는 등 전투 판단이 달라지는지 검증한다.
- [x] SpawnPoint에 후방 사격·근접 압박·돌진 경로 확보 등의 배치 역할을 지정한다. (Spawn-1 Unity 배치 역할 적합성·불일치 거부·512 seed 검증, 2026-09-30)

- [ ] 같은 seed와 콘텐츠 버전에서 Layout·장식·파괴물·Encounter·활성 SpawnPoint 선택을 재현한다.

## 11. 일정이 밀릴 때의 축소 순서

다음 순서로 범위를 줄인다.

1. Room Layout 확장 후보와 병행 UX를 제외한다.
2. 상점(Special-4)을 제외한다.
3. 구덩이 통로를 제외하고 비밀방은 폭탄 벽 파괴 진입만 유지한다.
4. Floor-1 층 규모 확장을 제외하고 기존 6~8방에 특수방을 넣는다.
5. 장애물 Layout 수를 방 크기별 1종으로 줄인다.

다음 항목은 축소하지 않는다.

- 드롭 후보 자원의 획득·보유·Run 종료 초기화
- 파괴 가능한 장애물과 재방문 상태 보존
- 적이 장애물에 끼어 방 클리어가 막히지 않는 대응
- 스폰 위치별 후보와 seed 재현
- 방 난이도와 거리 가중 선택
- 소모 자원 없이 필수 진행 경로 완료 보장
- 자원·보상·방 상태의 중복 지급 방지와 전체 Run 회귀 검증
