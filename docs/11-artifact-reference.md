# 트릭컬 리바이브 아티팩트 원본 참고표

> 이 문서는 팬게임 아이템 설계 시 원작 효과와 조합 아이디어를 비교하기 위한 참고 자료다.
> 원작 문구는 밸런스 확정안이 아니며, 팬게임 구현 단계에서 효과·수치·시너지를 별도로 조정한다.

## 문서 사용 기준

- 수록 범위: 아티팩트 102개
- 생성일: 2026. 08. 23. (Asia/Seoul)
- `원본 효과`는 나무위키 카드 정보 틀의 설명/수치 필드를 순서대로 합친 문구다.
- `Lv.1 능력치`와 `레벨별 수치`는 원문에 값이 있는 항목만 표시한다.
- `애착 효과`와 `원문 해설`은 시너지 후보를 찾기 위한 참고 정보이며 팬게임 설계안이 아니다.
- 원문에 제목이나 짧은 메모만 있는 항목은 확인 가능한 필드만 기록하고 나머지를 `-`로 표시한다.
- 나무위키 매크로를 제거하는 과정에서 표시가 단순화될 수 있으므로 정확한 원문은 [원본 보관 파일](references/trickcal-revive-artifacts-namuwiki-source.txt)에서 대조한다.
