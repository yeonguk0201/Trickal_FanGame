# 로딩 화면 시안 v1

`loading-preview.html`을 브라우저에서 열면 된다. 이미지와 ONE Mobile POP 글꼴을 포함한 UTF-8 독립 HTML로, 인터넷 연결이 필요 없다.

- 참고 이미지의 연두 체크 배경, 나무·별 반복 무늬, 원형 초상, 좌상단 말풍선, 수식어 띠, 흰 이름표, 하단 로딩 바를 배치했다.
- 초상은 `game/Assets/Art/Characters/Player/Character_Erpin.png`를 임시로 재사용한다. 참고 이미지의 크레파스 초상 원본을 확보하면 **다른 초상 넣기**로 교체할 수 있다.
- 기본 해상도는 1920×1080이며 **참고 비율**은 1920×884다. 비율 전환 시 해당 비율의 기본 배치로 초기화된다.
- 레이어를 직접 드래그하고 모서리로 크기를 조절한다. Shift는 비율 유지, 방향키는 1px 이동, Shift+방향키는 10px 이동이다.
- 오른쪽 패널에서 위치·크기·회전·겹침 순서·표시·글자 크기·문구·글자색을 바꾼다. 로딩 바와 퍼센트는 진행률 슬라이더로 함께 바뀐다.
- **원형 캐릭터 초상**을 선택하면 **캐릭터 크기 (%)** 수치와 **원 안 캐릭터 크기** 슬라이더로 25~400% 확대·축소할 수 있다. 프레임 크기는 그대로이며 캐릭터 중심 기준으로 확대한다. 자동 저장·JSON·수정 요청문에 함께 포함하고, 기존 저장값에는 100%를 적용한다.
- 초상 선택 후 **캐릭터 X/Y (px)**로 원 안의 캐릭터 위치를 조절한다. **드래그로 원 안 캐릭터만 이동**을 켜거나 Alt+드래그하면 원형 틀을 고정한 채 이동한다. 이 모드 또는 Alt와 함께 방향키를 눌러도 내부 캐릭터를 이동한다. 회전과 미리보기 축소율을 반영하고, 확대율에 관계없이 캔버스 픽셀 단위로 이동한다. 기존 저장값의 이동량은 0이며 자동 저장·JSON·수정 요청문에 함께 포함한다.
- **미리보기**는 편집 UI와 선택선을 숨긴다. Esc로 편집 화면으로 돌아온다.
- 배치는 파일별 키로 브라우저에 자동 저장된다. 저장 공간을 사용할 수 없으면 JSON을 수동 복사해 보관한다.
- **JSON 내보내기** → 복사 → **JSON 적용**으로 배치를 왕복한다. **수정 요청문**은 채팅으로 전달할 수 있는 텍스트를 만든다.
- JSON 좌표는 캔버스 좌상단 원점, 레이어 좌상단 기준, 회전은 레이어 중심을 기준으로 시계 방향이다.

재생성: 저장소 루트에서 `python docs/ui-mockups/loading-v1/build.py`.

Unity 런타임·Scene·Prefab은 변경하지 않았다. 텍스트·자산 포함과 JavaScript 문법은 정적 검사한다. 이 세션의 브라우저에서는 로컬 서버 연결이 시간 초과되고 로컬 파일 URL도 지원되지 않아 실제 화면 및 조작 검증을 완료하지 못했다. 실제 확인 시 첫 화면의 초상·글꼴 표시, 레이어 선택과 이동, 축소·회전 상태의 모서리 조절, Shift 비율 유지, 수치 편집, 새로고침 후 저장 복원, JSON 왕복, 초기화를 확인한다.
