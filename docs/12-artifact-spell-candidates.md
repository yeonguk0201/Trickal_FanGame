# 아티팩트 및 스펠 후보 목록

> 이 문서는 팬게임에 추가할 아티팩트와 스펠 후보를 정리한 문서다.
> 원작 트릭컬 리바이브의 아티팩트/스펠을 기반으로 하되, 이 게임에 맞게 효과를 조정한다.

## 확정 방향

- 아티팩트와 스펠은 같은 `Item` 보상 체계에서 획득·중첩·표시·저장한다.
- `ItemKind`는 `ARTIFACT`와 `SPELL`을 구분한다. 별도 스펠 슬롯이나 인벤토리는 만들지 않는다.
- 기존 `item-*` ID는 안정 계약으로 보존한다. 신규 아티팩트는 `artifact-*`, 신규 스펠은
  `spell-*` 형식의 ID를 사용해 종류를 구분한다.
- 보물방과 1·2층 보스 보상의 후보 3개는 활성 아티팩트와 스펠을 합친 하나의 풀에서 추첨한다.
- 종류별 최소 등장 수나 보정은 두지 않는다. 한 선택지에 아티팩트나 스펠만 3개 나올 수 있다.
- 현재 적용 중인 등급 가중치는 유지하며, 후보 3개는 서로 다른 Item으로 구성한다.
- 비활성 Item과 최대 스택에 도달한 Item은 후보에서 제외한다. 획득 가능한 Item이 3개 이상이면
  Item 3개, 2개면 Item 2개와 회복, 1개면 Item 1개와 회복, 0개면 회복만 표시한다. 회복 후보는
  최대 HP의 25%를 회복하며 한 선택 화면에 하나만 등장한다.
- 비어 있거나 유효한 활성 Item이 하나도 없는 잘못된 풀에는 회복 후보를 만들지 않는다. 구성
  오류를 회복으로 숨기지 않고 후보 생성 실패로 처리한다.
- 후보는 Run seed와 해당 보상 지점의 진행 상태로 결정한다. 같은 seed와 같은 진행 상태에서는
  같은 후보가 나오며 재방문으로 다시 추첨되지 않는다.
- 선택한 하나만 효과를 적용하고 획득 순서와 Run 결과에 기록한다.

## 공통 표현과 발동 규칙

- `1회성`은 별도 설명이 없으면 **Run당 1회**를 뜻한다.
- 이 문서의 후보 효과에서 `공격력` 또는 별도 출처가 없는 `피해량`은 **기본 공격 피해량**을 뜻한다.
  스킬·지속 피해·추가 투사체 등 다른 출처까지 적용할 때는 효과 설명에 명시한다. 현재 구현된
  아티팩트의 확정 효과와 계산식은 [12-skill-system-plan.md](./12-skill-system-plan.md)를 우선한다.
- `다음 입장한 방`은 새 전투 Encounter가 시작되는 방만 뜻한다. 시작방·보물방·이미 클리어한 방 등
  전투가 없는 방에 들어가도 효과를 소비하지 않는다.
- `HP 50 이상`은 현재 HP가 최대 HP의 50% 이상인 상태를 뜻한다.
- `방어막 20%`처럼 기준이 생략된 비율 방어막은 최대 HP를 기준으로 계산한다.
- `공격 N타`는 실제 적중 횟수를 센다. 다중 타격은 각 적중을 따로 세되, 플레이테스트에서 지나치게
  빠르게 발동하면 효과별 내부 쿨타임이나 한 시전당 1회 집계를 검토한다.
- `죽음 무효`는 HP가 0이 되는 피해를 적용하기 전에 그 피해를 무효화하고 후속 무적을 적용한다.
  사망·게임오버 이벤트는 발생시키지 않는다.
- `최대 SP +1`은 최대 슬롯만 늘리고 현재 SP는 채우지 않는다.
- 원작의 웨이브 시작 효과는 새 전투 Encounter 시작, 웨이브 종료 효과는 방 클리어에 대응한다.
  클리어한 방 재입장으로 시작 효과를 다시 발동하지 않는다.

## 확정 상세 효과 (사용자 결정, 2026-10-06)

아래 26종은 위 후보 표의 간단한 적용안보다 우선한다. 아직 구현 전이며 안정 ID는 구현 조각에서
[23번 계약](./23-item-classification-contract.md) 규칙으로 정한다. "남은 것"은 구현 조각을
시작할 때 다시 확인한다.

전제:

- 플레이어 HP·방어막은 반 칸 정수 단위이고 적 피해는 최소 1칸이므로 % 피해 감소·소량 % 회복은 쓰지 않는다.
- 적에게는 치명타가 없으므로 치명타 저항 효과는 두지 않는다.
- 스펠은 모두 일회용(`ItemKind.SingleUseSpell`, 최대 1스택)이다. 위 "스펠 후보" 표의 상시 버프 적용안은 폐기한다.
- 상태이상 수치는 [24번 §4.8](./24-attack-modifier-contract.md)을 따른다. 쓰라림은 상태이상으로 만들지 않는다.
- **체력·방어막 상한**: **현재 HP와 방어막을 합해 15칸**까지다(사용자 결정). 구현된 갑옷축제 초대장도
  이 상한을 따르도록 바꾼다(현재 코드는 상한 없이 합산). 상한을 넘기는 쪽의 획득분이 잘린다(사용자 확정). 방어막 획득은 넘는 만큼 버리고,
  회복도 넘는 만큼 버리며 이미 가진 방어막은 깎지 않는다. 상한에 닿아 있으면 하트·방어막 픽업은 줍지 않고 바닥에 남는다.
- **효과형 공격 아티팩트의 기본 스탯**: 공격 관련인데 효과만 있는 아티팩트에는 등급별 스탯을 함께 준다(사용자 결정).
  수치는 고급 +3%, 희귀 +5%, 전설 +8%로 확정한다. 스탯 종류는 아이템 성격에 맞춘다(공격력·치명타 확률·스킬 피해).
- **방어막 픽업**을 새로 만든다. 1개가 방어막 1칸이며 상한에 닿아 있으면 줍지 않고 바닥에 남는다(하트 픽업과 같음).

## 기존 아티팩트 수정 후보

아래 항목은 이번 첫 구현 묶음에 포함하지 않는다. 테스트 단계라 개발 DB 초기화는 가능하지만,
기존 ID의 의미를 조용히 바꾸지 않는다. 실제 채택할 때는 Unity·Backend·seed·테스트·문서를 한 번에
갱신하고 개발 데이터 초기화 여부를 명시하는 계약 마이그레이션으로 진행한다. 기존 계약 보존이
필요하면 기존 ID를 비활성화하고 새 효과에 새 ID를 부여한다.

- `item-08` 코미의 베개 (HP-3, 2026-09-28에 적 2마리 처치마다 반 칸 회복으로 변경해 아래 검토는 종료): 적 처치 시 최대 HP의 5%를 회복하던 효과가 회복을 지나치게 쉽게
  만드는지 확인한다. 변경한다면 Run당 1회, HP가 30% 이하가 되는 피해를 받은 뒤 5초 동안 최대
  HP의 총 40%를 회복하는 안을 검토한다.
- `item-11` 다야의 다이아몬드 커터: 현재 관통·분열 효과와 이름의 연결이 약한지 확인한다. 디버프가
  걸린 적 대상 기본 공격·스킬 피해 증가를 다이아몬드 커터의 새 효과로 검토하되, 현재 관통·분열
  효과도 별도 이름과 신규 안정 ID로 보존할 가치가 있는지 함께 판단한다.
  - **결정(2026-10-06, 구현 전)**: 이름과 관통·분열 개념은 유지하고 분열 모양만 바꾼다. 적을 맞히면 적 뒤쪽 부채꼴
    3개 대신 **그 적의 상하좌우 4방향으로 기본 공격 탄보다 작은 투사체**가 퍼진다. 구현할 때는 `SplitAfterPierce (16)`의
    계산식을 조용히 바꾸지 말고 위 마이그레이션 절차(Unity·Backend 카탈로그·seed·검증기·문서, 필요하면 새 효과 번호)로
    진행한다.
  - **세부 결정(2026-10-06)**: **관통 +1을 없앤다.** 탄이 적을 맞히면 그 탄은 사라지고, 맞은 적의 위치에서 화면 기준
    상하좌우 4방향으로 분열탄이 나간다(아이작 방식). 분열탄 피해는 **플레이어 현재 공격력의 50%**, 크기는 **기본 탄의 50%**다.
    분열탄 사거리는 지금 분열탄처럼 짧게 유지하며 플레이어의 사거리 증가 효과와 무관하다. 분열탄은 기본적으로 방금 맞힌
    적을 다시 맞히지 못하지만, **다른 출처의 관통 효과가 있으면 방금 맞힌 적도 다시 맞힐 수 있다.** 분열탄은 다시
    분열하지 않는다.
  - **관통과의 조합(2026-10-06)**: 다른 출처의 관통이 있으면 **본탄은 사라지지 않고 관통 수만큼 계속 날아간다.** 이때
    분열탄은 맞은 적의 안쪽에서 4갈래로 생기고 관통을 물려받으므로 그 적을 다시 맞혀 추가 피해를 준다. 관통이 없으면
    본탄은 사라지고 분열탄은 그 적을 맞히지 못한다. **본탄은 적을 맞힐 때마다 분열한다**(사용자 결정). 관통한 본탄이
    다음 적을 맞히면 그 적에서도 4갈래가 나온다. 분열탄 자체는 다시 분열하지 않는다.
