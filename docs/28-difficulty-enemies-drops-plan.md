## 2. 체급 곡선

### 2.1 현재 값

- 적 체력 배율(`FloorDifficultyScaler`): 1층 ×1.0, 2층 ×1.5, 3층 ×2.0. 일반 적과 보스 모두 적용.
- 적 피해(`HealthUnits.EnemyDamageUnitsByFloor`, 칸):

| 등급     | 1층 | 2층 | 3층 |
| -------- | --- | --- | --- |
| Light    | 1   | 1   | 1.5 |
| Medium   | 1.5 | 2   | 2.5 |
| Heavy    | 2   | 3   | 3.5 |
| Critical | 3   | 3.5 | 4   |

- 3층은 처치 시간 ×2와 받는 피해 ×1.5~1.75가 겹쳐 체감 난이도가 1층의 3배를 넘는다. 층마다 얻는 아이템은
  2~3개 정도라 따라잡기 어렵다.

### 2.2 방향(사용자 결정, 2026-10-16)

아이작처럼 숫자를 부풀리지 않고, 적의 구성과 패턴으로 난이도를 올린다. 플레이어가 강해진 체감을 남긴다.

- **체력**: 일반 적은 배율 없음(×1.0 고정). 보스만 깊이 배율을 유지한다.
- **피해**: 층마다 올리지 않는다. 현재 범위에서는 깊이 1~2는 기본값, 깊이 3에서 한 단계 올린다.
- **적 풀**: 기존 적을 테마 안 1/2/3층 단계로 나눠 층마다 등장 구성이 달라지게 한다.

미정:

- 보스 배율 값(현재 ×1.0/1.5/2.0 유지 여부).
- 깊이 3에서 올리는 "한 단계"의 값. 후보는 현재 1층 값 → 현재 2층 값 정도.
- 테마 1층에 배치할 기존 적과 2·3층에 새로 추가할 적의 분류.

## 3. 장기 구조: 테마와 깊이

### 3.1 테마 순서(사용자 구상, 2026-10-16)

- 3층 단위로 테마가 바뀐다. 기본 순서는 **요정 → 수인 → 정령 → 엘프 → 마녀**.
- 시작 캐릭터의 종족 테마에서 시작한다. 그 다음에는 시작 테마를 뺀 나머지를 기본 순서대로 간다.
  - 에르핀(요정): 요정 → 수인 → 정령 → 엘프 → 마녀
  - 정령 캐릭터: 정령 → 요정 → 수인 → 엘프 → 마녀
- 현재 범위는 요정 테마 3층뿐이다. 나머지 테마는 추후 확장이다.

### 3.2 두 축의 분리

- **깊이**(Run 안에서 몇 층째인지)가 강함을 정한다. 피해 단계, 보스 배율, 깊이에 따른 변형.
- **테마 안 층수**(1~3)가 다양함을 정한다. 그 테마의 어떤 적이 나오는지.
- 같은 마녀 적이라도 마녀 캐릭터에게는 깊이 1이라 1층 수준이고, 요정 캐릭터에게는 깊이 10이라 강하다.

### 3.3 깊이별 강함은 체력보다 변형으로

깊이에서 체력을 다시 올리면 지금 문제가 돌아온다. 후보:

- 챔피언·엘리트 확률을 깊이에 따라 올린다.
- 탄 개수·탄속·공격 간격을 깊이 단계별로 강화한다.
- 피해 단계는 테마 경계(깊이 4·7·10…)에서 계단식으로 올린다. 값은 미정.

### 3.4 늦게 들어간 테마의 1층이 쉬워지는 문제

깊이 10에서 들어간 테마 1층에 입문용 적만 나오면 패턴이 단조로워 쉬워진다.
적 풀 단계는 `max(테마 안 층수, 깊이에 따른 최소 단계)`로 고르는 것을 후보로 둔다.

### 3.5 콘텐츠 부담

- 모든 테마가 누군가의 1층이 될 수 있으므로 테마마다 입문용 적 세트가 필요하다.
- 테마당 쉬운 적 3, 중간 2, 어려운 2, 보스 정도로 잡으면 5테마에 30종이 넘는다. 가장 큰 장기 부담이다.

### 3.6 계약 영향(나중에 확인)

- 현재 코드의 `floorNumber`는 깊이와 테마 안 층수가 같다. 확장 때 두 값을 분리한다.
- Backend Run 기록이 층 번호를 저장하면 깊이·테마 구분이 필요해진다. 확장 시 `contract-drift-check` 대상.

  1/1.3로 줄인다. 예고·준비 시간은 그대로다. 몸은 자기 색에 회색 반투명(0.62/0.62/0.66, 알파 0.55)을 곱해 그린다(자폭형 붉어짐·잠복형
  상태 색은 그 위에 보인다). 흰 외곽선은 그대로 보이며 몸 알파를 따라 흐려진다. 체력바는 85%에서 줄어드는 생명을 보인다.
- 처치 판정: 사망 이벤트(`Health.Died`)가 최종으로 쓰러질 때만 나므로 처치 효과(베개 등)·방 클리어·누루링 분열은 모두
  그때 일어난다. 처치는 불사 중 플레이어의 마지막 타격(없으면 쓰러뜨린 타격)으로 인정한다. 환경 피해로 쓰러지고 플레이어가 다시 치지
  않았으면 처치 효과가 없다.
- 자폭형: 자기 자폭(자기 자신이 준 피해)은 유예하지 않아 바로 죽고 폭발한다. 플레이어나 다른 폭발에 쓰러지면 불사 3초 동안 접근·자폭을
  계속할 수 있다.
- 구현: `Health`에 치명타 유예(`SetLethalDeferral`)와 생명 소모(`DrainHealth`, 피격이 아니라 피해 숫자·피격 번쩍임 없음, 무적 무시)를
  더했다. 레비의 단도(플레이어 치명타 취소)와는 별개다.
