## 2. 체급 곡선

### 2.1 현재 값

- 적 체력 배율(`FloorDifficultyScaler`): 1층 ×1.0, 2층 ×1.5, 3층 ×2.0. 일반 적과 보스 모두 적용.
- 적 피해(`HealthUnits.EnemyDamageUnitsByFloor`, 칸):

| 등급     | 1층 | 2층 | 3층 |
| -------- | --- | --- | --- |
| Light    | 1   | 1   | 1.5 |
| Medium   | 1.5 | 2   | 2.5 |
| Heavy    | 2   | 3   | 3.5 |
| Critical | 3   | 3.5 | 4   |

- 3층은 처치 시간 ×2와 받는 피해 ×1.5~1.75가 겹쳐 체감 난이도가 1층의 3배를 넘는다. 층마다 얻는 아이템은
  2~3개 정도라 따라잡기 어렵다.

### 2.2 방향(사용자 결정, 2026-10-16)

아이작처럼 숫자를 부풀리지 않고, 적의 구성과 패턴으로 난이도를 올린다. 플레이어가 강해진 체감을 남긴다.

- **체력**: 일반 적은 배율 없음(×1.0 고정). 보스만 깊이 배율을 유지한다.
- **피해**: 층마다 올리지 않는다. 현재 범위에서는 깊이 1~2는 기본값, 깊이 3에서 한 단계 올린다.
- **적 풀**: 기존 적을 테마 안 1/2/3층 단계로 나눠 층마다 등장 구성이 달라지게 한다.

미정:

- 보스 배율 값(현재 ×1.0/1.5/2.0 유지 여부).
- 깊이 3에서 올리는 "한 단계"의 값. 후보는 현재 1층 값 → 현재 2층 값 정도.
- 테마 1층에 배치할 기존 적과 2·3층에 새로 추가할 적의 분류.

## 3. 장기 구조: 테마와 깊이

### 3.1 테마 순서(사용자 구상, 2026-10-16)

- 3층 단위로 테마가 바뀐다. 기본 순서는 **요정 → 수인 → 정령 → 엘프 → 마녀**.
- 시작 캐릭터의 종족 테마에서 시작한다. 그 다음에는 시작 테마를 뺀 나머지를 기본 순서대로 간다.
  - 에르핀(요정): 요정 → 수인 → 정령 → 엘프 → 마녀
  - 정령 캐릭터: 정령 → 요정 → 수인 → 엘프 → 마녀
- 현재 범위는 요정 테마 3층뿐이다. 나머지 테마는 추후 확장이다.

### 3.2 두 축의 분리

- **깊이**(Run 안에서 몇 층째인지)가 강함을 정한다. 피해 단계, 보스 배율, 깊이에 따른 변형.
- **테마 안 층수**(1~3)가 다양함을 정한다. 그 테마의 어떤 적이 나오는지.
- 같은 마녀 적이라도 마녀 캐릭터에게는 깊이 1이라 1층 수준이고, 요정 캐릭터에게는 깊이 10이라 강하다.

### 3.3 깊이별 강함은 체력보다 변형으로

깊이에서 체력을 다시 올리면 지금 문제가 돌아온다. 후보:

- 챔피언·엘리트 확률을 깊이에 따라 올린다.
- 탄 개수·탄속·공격 간격을 깊이 단계별로 강화한다.
- 피해 단계는 테마 경계(깊이 4·7·10…)에서 계단식으로 올린다. 값은 미정.

### 3.4 늦게 들어간 테마의 1층이 쉬워지는 문제

깊이 10에서 들어간 테마 1층에 입문용 적만 나오면 패턴이 단조로워 쉬워진다.
적 풀 단계는 `max(테마 안 층수, 깊이에 따른 최소 단계)`로 고르는 것을 후보로 둔다.

### 3.5 콘텐츠 부담

- 모든 테마가 누군가의 1층이 될 수 있으므로 테마마다 입문용 적 세트가 필요하다.
- 테마당 쉬운 적 3, 중간 2, 어려운 2, 보스 정도로 잡으면 5테마에 30종이 넘는다. 가장 큰 장기 부담이다.

### 3.6 계약 영향(나중에 확인)

- 현재 코드의 `floorNumber`는 깊이와 테마 안 층수가 같다. 확장 때 두 값을 분리한다.
- Backend Run 기록이 층 번호를 저장하면 깊이·테마 구분이 필요해진다. 확장 시 `contract-drift-check` 대상.

## 4. 아이템 풀 분리

- 방향: 출처별로 풀을 나눈다(사용자 동의, 2026-10-16).

- 아이템 ID는 바꾸지 않고 풀 소속만 데이터로 붙인다.

미정: 아이템별 풀 소속, 한 아이템의 여러 풀 소속 허용 여부, 풀별 최소 개수.

## 5. 드롭률

### 5.1 현재 값

- 방 클리어(`Week17Resource3Setup`): 33% 확률로 1회. 가중치 하트 30 / SP 30 / 엘리프 20 / 열쇠 12 / 폭탄 8.
  - 방당 기대값: 열쇠 약 4%, 폭탄 약 2.6%, 엘리프 약 6.6%.
  - 한 층에 전투방이 5개 정도면 층당 열쇠 0.2개, 폭탄 0.13개.
- 기본 장애물(`Week18Obstacle1Setup`): 3%.

### 5.2 방향

- 확률을 먼저 고치지 않고 **층당 목표치**를 먼저 정한 뒤 확률을 역산한다.
  - 후보: 층당 열쇠 1~2, 폭탄 1~2, 2층 상점에서 아이템 1개를 살 만큼의 엘리프.
- 수단 후보: 클리어 드롭 33% → 50% 안팎, 엘리프 가중치와 개수 증가.
- **보정 장치(pity)**(사용자 호감, 2026-10-16): 일정 방 수 동안 열쇠(또는 폭탄)가 안 나오면 다음 드롭을 확정.
  seed 재현과 재방문 보존을 지켜야 한다.

### 5.3 1층 열쇠 콘텐츠

두 후보 중 미정:

- A. 1층에서 열쇠로 여는 방·상자를 생성하지 않는다(사용자 원안).
- B. 1층에 잠긴 콘텐츠가 있으면 열쇠 1개를 보장한다.

## 9. 층 분류(Curve-1) 결정(2026-10-24)

- **분류 기준**: 1층 정면 대응, 2층 예고 읽기, 3층 판단과 위치(엄폐 깨기·위치 예측·우선순위·정리).
- **등장 시작 층(사용자 결정)**:

  | 층  | 처음 등장하는 적                                                              |
  | --- | ----------------------------------------------------------------------------- |
  | 1층 | 불효자손, 산사모-활발, 고혈당 요정(저격), 쥬비                                 |
  | 2층 | 산사모-순수, 저혈당 요정-순수(돌진), 저혈당 요정-활발, 자폭형                  |
  | 3층 | 누루링-요정전사, 대왕쥬비, 곡사형, 잠복형                                     |

- **누적과 가중치(사용자 결정, 2026-10-24)**: 이전 층 적도 계속 나온다. 그 층에서 처음 나오는 적은 가중치 ×1.5,
  두 층 아래 적은 ×0.5. 후보가 층 조건으로 빠지면 남은 후보로 가중치를 재분배한다.
- **Encounter 영향**: `elite-pair`(돌진+저격)는 돌진 때문에 2층부터. `crossfire`·`pressure`는 1층에서 산사모-순수·돌진·
  저혈당-활발·누루링 후보가 빠진다. 선언 위협 범위를 층별로 검증한다. 같은 seed의 적 구성이 바뀌므로
  `encounterContentVersion`을 올린다. 새 적 전용 조합(곡사형+근접, 대왕쥬비 둥지 등)은 각 새 적 조각에서 추가한다.
- **산사모-순수 조정 방향(사용자 결정)**: 플레이 체감상 가장 어려운 적이다. 요정 테마가 Run의 첫 테마(깊이 1~3)일
  때는 3발 발사·에임 보정 없음, 늦게 들어간 요정 테마(깊이 4 이후)에서는 4발 발사·약한 에임 보정. 깊이 단계별
  패턴 강화(§3.3)의 첫 사례이며, Depth-0 전에는 3발·보정 없음만 적용한다(Curve-1).
- **변형 확률(사용자 결정)**: 챔피언은 적 한 마리 기준, 엘리트는 전투방 단위(방당 최대 1마리).
